测试条件与边界

  • 同一台机器，相同节点配置、30 份订阅记录；三轮交替运行顺序，读取并发 1 / 4，写入并发 1。
  • 流量设置、节点修改及 YAML 保存每次更改实际字段；内容未变保存单列。
  • 只启用生产 HTTP Handler；不启用定时更新、SSH、计量和外部网络访问，不包含 TLS 加密或代理转发速度。
  • 真实备份与镜像文件保留。Go 的 fsync 成本与 Python 原子替换策略不同；写入结果不是严格同等持久化语义下的语言对比。
  • Go 仍在迁移，完整协议校验覆盖尚未对齐；这里测试的是相同有效数据经过当前共有接口的表现，不代表最终完整功能对等的结果。
  • RSS 为场景前后采样的最大值，不是精确峰值。Windows 文件系统与后台负载影响结果，不能直接外推线上 Linux。
