# 节点入口连通性检查

v0.3.16 在「节点管理」加入单节点「检查入口」和批量「检查入口连通性」，结果直接显示在页面中。每次选择 1–30 个已保存节点，每批最多 6 个并发；整个面板同时运行一批检查。可以停止检查，切换页面后不会展示旧请求的迟到结果。

## 检查内容

探测从 **面板服务器** 发起，解析节点地址后连接其 TCP 端口。显示节点名称、地址、检查时间、TCP 建连耗时或失败原因。失败耗时为空，不显示成 0 ms。

- 支持 VLESS、VMess、Trojan、Shadowsocks、Snell、HTTP、SOCKS5 的 TCP 入口。
- Hysteria2、TUIC、Mieru 及 QUIC/KCP/UDP 传输标记不适用，不以 TCP 不通判定其故障。
- 客户端链式代理只检查保存的节点地址，不经前置代理。服务器内部中转只检查入口端口。
- 不验证 TLS/REALITY 握手、用户凭据、代理出口、下载速度或 UDP；不代表手机、运营商或 Telegram 测速机器人的网络结果。端口可达不等于代理可用。

## 访问与资源控制

管理员通过 POST `/admin/api/nodes/probe` 提交当前订阅节点名称。普通用户不可调用；沿用 HTTPS、登录和同源校验。只使用订阅中已保存的端点，不接受临时目标地址；返回结果不包含 UUID、密码或完整分享链接。

地址格式、端口与解析后的公网 IP 校验由探测组件执行，禁止私网、回环、链路本地、元数据地址及混合私网 DNS 结果。解析后直接连接已校验 IP，不再次按域名解析。每个目标最多 3 秒，整批最多 18 秒；取消请求停止后续批次。不会更改节点配置或生产服务。

## 验证范围

接口验证管理员/普通用户隔离、CSRF、方法限制、未知/重复/超量节点、批次限制、忙碌拒绝、取消、凭据不回传与不适用协议；已有探测测试覆盖私网及 localhost DNS 拒绝。浏览器覆盖单台/批量结果、失败不显示 0 ms、取消和切页迟到响应，以及六主题四种宽度。浏览器使用受控响应，不将模拟结果当作真实节点联网证明。

## v0.3.17：普通 TLS 分阶段验证

节点卡片「TLS 检查」和批量「检查 TLS 证书」复用入口检查区域，先判断 DNS/TCP，再验证普通 TLS。显示独立的 TCP/TLS 耗时、TLS 版本、已验证证书到期时间；证书域名错误、不受信任、过期/尚未生效、其他无效证书和握手超时分别展示。

使用节点保存的 SNI/servername（缺省使用服务器地址）及 ALPN，始终执行系统证书信任验证，即使节点开启跳过证书验证也不绕过。自签证书可能被判为不受信任，这不等于节点在关闭校验的客户端中一定不能使用。TLS 最低版本 1.2。

REALITY 使用专门认证流程，不执行普通 TLS 验证；普通明文节点和 REALITY 节点仅执行原 TCP 检查，并明确标注 TLS 不适用。Hysteria2/TUIC 等 QUIC 协议仍不适用。TLS 通过不代表代理用户认证、WebSocket/gRPC 应用协议、落地出网或带宽测试通过。

TLS 每个目标最长 5 秒、6 并发，混合检查整批最长 28 秒；未完成目标保持未完成，不计为成功。解析后的所有地址先验证，连接固定 IP，SNI 只用于 TLS；不会为 SNI 另发网络请求。多个地址为 TCP 尝试分配子超时，避免第一个不可达地址耗尽全部时间。

验证采用本地 TLS 服务和受信测试证书，覆盖可信、域名不符、不受信、过期、非 TLS 响应、超时与取消；接口覆盖普通 TLS、明文、REALITY 分流，浏览器覆盖批量/单台、证书信息、六主题四宽度。未向生产节点发送代理凭据。
