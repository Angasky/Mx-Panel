## 尚不能标记完成的事项

| 边界 | 当前处理及完成条件 |
| --- | --- |
| 面板中转写入/回滚结果不明 | 保留取消意图并禁止后续创建。面板 API 没有事务完成/取消屏障；观察到一次配置不能证明旧请求不会迟到覆盖。需远端可核验的请求终止机制或独立环境中确认原请求结束，不能假报取消成功 |
| 旧独立核请求没有取消屏障 | 若仍看到写入前配置，不认为取消成功；原写入确认结束后再恢复。新请求已使用屏障 |
| 完全缺失身份或归属证据的旧资源 | 有原连接/原中转配置可走显式核验流程；没有任何证据不能自动接管或删除，须先恢复备份或由管理员重建 |
| sing-box 1.14.4 → Xray 26.10.31 Reality | 当前组合真实握手失败：两者对 X25519MLKEM768 的处理不兼容。已验证 sing-box 1.14.4 → Xray 26.4.25 的真实 Reality 连接、独立计量和撤销。26.9.30 / 26.7.28 测试仍失败；默认 26.10.31 组合仍不兼容。旧版组合仅为已验证替代链路，不代表所有新协议兼容，未自动降级；不能用关闭校验替代 Reality 认证 |
| Xray 跳过 TLS 校验 | Xray 26.10.31 已移除 allowInsecure，真实配置启动测试确认不再支持。sing-box 转换可保留显式策略；Xray 需使用可信证书或后续适配证书固定字段，不能生成无效配置 |
| 共用加密端口按用户限速 | Python 本身也拒绝这一组合；需要用户级内核限速或独立端口设计。当前专属整入站端口限速可用，认证用户绑定不开放此操作 |
| 未知高级参数及任意协议切换 | 已支持明确的模板、转换与编辑矩阵；不能宣称所有第三方字段都无损支持。未知且无法表达的参数明确报错 |
| 实机验收 | SSH、3x-ui 安装、systemd 更新/回滚/卸载、低资源与掉电恢复、公网 UDP/IPv6、客户端 App 需独立可重置环境。未在运行中的 Python 生产服务上执行这些操作 |
| 发布与切换 | 按用户要求只保存本地包；未发布、未切换服务 |
