# 服务器 URI 筛选

在订阅的“客户端订阅”窗口选择服务器，复制对应客户端地址即可。支持 v2rayN、v2rayNG、V2Ray 和 Shadowrocket 基础节点 URI。选择全部时恢复原有完整配置与客户端格式。

服务器选项来自活动托管绑定的 importedNodes 身份指纹与当前节点匹配。名称改变不影响匹配；连接身份改变需要重新同步托管记录。旧记录没有身份指纹、外部节点、已撤销绑定以及跨服务器归属冲突均不会猜测归属。计数表示归属节点数，不保证每种客户端都支持这些节点。

下载使用 `/convert/<订阅凭据>/<格式>?server=<服务器ID>`。未知服务器、无匹配节点及不支持格式拒绝导出；空或重复参数拒绝请求。原始 `/sub/` 不接受服务器筛选，避免错误返回完整订阅。

筛选不是权限控制。持有链接的人移除 server 参数仍可读取原订阅。订阅凭据、IP 白名单、浏览器限制、有效期及额度保持原有检查，用量仍按整个订阅统计。不提供完整分流或主备配置的裁剪。

验证覆盖身份归属、同 IP 不同凭据、冲突与失效记录、非修改性、HTTP GET/HEAD、参数拒绝及管理端格式报告；浏览器交互使用隔离面板与模拟转换响应。未进行真实客户端网络连接验收。
