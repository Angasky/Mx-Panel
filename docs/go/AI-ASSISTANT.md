# AI 协助

从 v0.2.1 起，左侧 **AI 协助 → 接入设置** 可接入自己的模型。普通用户从「我的订阅」进入，同样使用自己的 Key。默认关闭，面板不提供公共额度。

## 悬浮聊天窗口（v0.2.2）

登录后右下角常驻 AI 按钮，点击展开聊天窗口，无需离开当前页面。按钮和窗口标题栏均可拖动，位置保存在当前浏览器；屏幕大小变化时自动限制在可视区域。按钮也支持方向键移动。

点击标题栏「−」或在窗口内按 Esc 收起；输入草稿和当前对话仍保留，正在进行的回复继续等待。切换面板功能不会中断回复；需要取消时点击「停止」。退出登录会取消请求并清空当前页面中的 AI 内容，避免下个账号看到对话。刷新后可从对话记录继续，未发送的草稿不会持久保存。

## 大工作区与运维 Agent（v0.2.4）

默认窗口宽度提升到 720px，桌面可拖动边角调整大小，标题栏「放大」切换最大化工作区。手机保持屏幕内显示。

管理员在聊天顶部选择运行模式：

- **仅问答**：不访问机器、不执行命令，默认选中。
- **Agent · 当前面板服务器**：诊断运行面板的主机；经确认的脚本使用面板服务实际账号权限，常见 systemd 部署为 root；容器部署仅能访问容器环境，默认仍是非 root 账号，不会获得宿主机管理权限。
- **Agent · 已接入服务器**：通过该服务器保存的 SSH 凭据和主机指纹连接；仅接入探针或 HTTP 面板但未配置 SSH 的服务器不能执行机器命令。

可用操作：

| 操作 | 行为 |
| --- | --- |
| 系统诊断 | 固定命令读取内核、负载、内存、磁盘、inode、面板/Nginx/Xray/sing-box 服务状态和监听端口；结果发送给所配置模型，并显示在对话中。 |
| 修复脚本 | 模型生成完整 bash 脚本、影响与回滚建议；点击「审阅并执行」，核对目标并勾选确认后才运行。脚本使用真实主机权限，回滚建议不等于自动备份。 |
| 创建节点 | 先选择目标订阅，提供协议模板、端口、伪装域名或证书路径等信息；确认后调用现有节点创建及订阅独立用户流程。 |
| 创建中转 | 选择入口服务器和订阅，提供落地链接及入口配置；确认后调用现有中转创建流程。落地链接含凭据，粘贴到对话即会发送给所配置模型。 |

Reality 创建沿用现有 SNI 校验，需先在面板 SNI 工具中完成目标域名测试；TLS 模板需提供现有有效证书路径，本模块不自动申请证书。

Agent 使用统一 JSON 计划协议兼容四种模型接口，不依赖供应商特定工具 schema。模型必须遵循结构化输出约定；格式错误会中止，不从普通文字中提取并执行命令。生成计划每轮最多 3 次模型决策，总等待 55 秒；耗时较长的问题需要分轮继续。

写操作计划绑定固定机器、订阅和参数，有效期 15 分钟；目标连接资料发生变化时需要重新生成。确认记录在执行前持久保存，重复确认、重启或请求重试不会再次运行同一计划。状态 `running` 在服务重启后可能代表执行中断，必须核对实际状态，不自动重放。管理员可取消未执行计划。普通用户没有 Agent 权限。

脚本和输出、创建参数及状态在服务器加密保存，最多保留最近 40 条操作记录；删除对话同时删除所属操作记录。脚本输出最多保留 32 KB，仅向管理员展示，不自动发送给模型；模型仅收到执行状态，后续可重新诊断。固定诊断输出不读取配置密钥，但包含主机运行状态、端口与地址；选择 Agent 模式即允许把这些诊断资料交给所选模型。

v0.2.6 起，确认后提交后台任务并立即返回任务状态，整项操作最多 3 分钟，其中验收脚本最多 45 秒。脚本超时会取消本机进程组或关闭 SSH 执行连接；远端命令可能已经改变状态，无法保证回滚。接口失败也可能已创建部分资源，需在节点页核对，不应反复新建。`completed` 仅表示命令退出码为 0 或创建接口成功返回，故障是否修复仍应复查。重启面板服务会中断本次请求；审阅前应准备外部 SSH 恢复方式。

本版提供有确认步骤的机器诊断与操作能力，不保证自动修复任意程序缺陷，也不会自动提交源码补丁或自行重装系统。

## v0.2.5 安全更新

更换 AI 接入设置会撤销旧的待执行计划。本机计划绑定当前机器和启动实例，重启系统或迁移数据后需要重新生成；SSH 命令使用已核验的连接快照。脚本使用固定的最小环境，不继承面板进程的环境变量；这不是 root 沙箱，文件访问权限仍由执行账号决定。重启服务后的未知执行显示为「执行中断或结果未知」，不能直接重放。

详见 [安全与功能验收报告](AI-SECURITY-REVIEW-20261114.md)，包括已修复问题、覆盖范围和仍未实现的无人值守能力。

## 后台执行、验收与回滚（v0.2.6）

确认操作后立即创建后台任务，不再让浏览器等到命令结束。刷新、收起和页面跳转不会取消已批准的操作。重新打开对应对话会读取加密持久化记录，运行中自动刷新状态。任务仍在同一面板进程内执行；进程或机器重启后的未完成记录显示为中断/结果未知，不自动重放写操作。这里恢复的是任务记录，不是盲目恢复命令执行。

修复计划可以包含三段独立内容：

1. **执行脚本**：实施修改。
2. **验收脚本**：必须和执行脚本一起审阅授权；主脚本成功后运行，退出码 0 表示指定检查通过，非零显示验收失败。未提供检查时明确显示「未配置自动验收」。验收脚本仍由模型生成，并非受限只读沙箱，不能省略审阅。
3. **回滚脚本**：计划中展示但不会随主操作执行。完成或失败后点击「生成回滚计划」，核对当前机器、备份和是否存在后续变更，再次确认后才恢复。每个原操作只生成一份回滚计划，避免反复覆盖。执行状态未知时不能直接回滚，应先核对实际状态。

主操作成功与验收通过分别记录；不能把某个自定义检查通过当成全面故障修复证明。任意 shell 脚本没有通用事务回滚，备份仍需执行脚本明确创建。节点/中转创建暂不自动生成删除资源的回滚脚本，应使用面板原生节点管理核对与撤销。

顶部「运行模式 / 目标机器」和「目标订阅」使用两列等高表单。AI 下拉框统一 36px、标签 18px，长名称单行截断；六套主题与手机均使用相同尺寸，避免全局主题把控件撑高。

## 接入格式

| 格式 | 默认基础地址 | 请求接口 |
| --- | --- | --- |
| OpenAI Chat Completions | `https://api.openai.com/v1` | `/chat/completions` |
| OpenAI Responses | `https://api.openai.com/v1` | `/responses` |
| Anthropic Messages | `https://api.anthropic.com/v1` | `/messages` |
| Google Gemini | `https://generativelanguage.googleapis.com/v1beta` | `/models/{model}:generateContent` |

选择格式、填写供应商提供的模型 ID 和 API Key，勾选启用，然后保存。支持使用相应格式的公网 HTTPS 兼容网关；更换地址或格式时须重新填写 Key，避免把原供应商密钥发送给另一服务。Gemini 使用原生格式，不是 OpenAI 兼容格式。

「保存并测试连接」会发送一条简短消息，可能产生费用；测试输出上限 128 tokens，推理型模型可能因预算不足没有正文。日常问答可设置 128–8192 输出 tokens。Chat 默认使用 `max_completion_tokens`；旧网关可勾选兼容 `max_tokens`。模型是否支持该参数以供应商为准。

## 问答和配置分析

支持多个对话、重命名、删除、复制回复和停止等待。可以询问分流策略、国内 App 联网问题、节点故障及面板使用方法。默认问答模式只提供建议。管理员可选择 Agent 模式，执行下述机器管理操作。

默认仅发送当前对话。选择「附带配置摘要」后，可以先预览再发送：

- 管理员摘要含协议、传输、TLS、策略组引用、部分域名规则和配置数量。节点与组名称替换为别名，不附带节点地址、UUID、密码、私钥或订阅链接。域名规则可能涉及使用习惯，请先检查预览。
- 普通用户只可附带自己获授权订阅的用量摘要，不可读取管理员配置。
- 用户自己粘贴的内容不会自动脱敏，请先删除敏感信息。已发送的摘要作为历史对话保留；如不想继续附带旧摘要，请新建对话。

## 保存和限制

Key 与对话正文在面板数据目录的 `ai/` 中加密存储，按账号隔离；接口不回显 Key。对话标题、时间和模型设置为明文元数据。备份时同时保留面板加密密钥；服务器管理员仍控制数据与密钥，并不构成对管理员的端到端加密。

每账号最多 20 个对话，每个保留最近 15 轮并按长度裁剪；每账号最多 1 个进行中的请求，全站最多 4 个。请求最长等待 55 秒，避免常见反向代理的 60 秒超时先中断连接。超长历史会从最旧轮次开始截断；本轮内容过长会提示新建对话。没有自动重试，避免重复计费。

点击停止或退出登录会取消聊天等待，并尝试取消上游请求；切换面板页面和收起窗口不会中断聊天。已经确认的机器操作不能通过收起窗口或退出登录回滚，需查看操作记录和目标机器实际状态；供应商可能已经处理或计费。上游失败不会写入虚假回复。各账号的 API 费用由填写 Key 的账号承担。外部服务实际保存策略取决于供应商；Responses 请求明确设置 `store:false`。

## Agent 验证范围

已通过隔离临时文件的真实命令执行测试，验证确认前不执行、重复确认拒绝、取消/过期/重启恢复、普通用户与跨域拒绝、加密记录、输出不自动传回模型、本机进程组超时取消和创建参数校验。浏览器覆盖最大化、目标选择、确认勾选、结果展示以及既有六主题移动布局。节点和中转调用已有控制器及其校验/幂等流程；本次不在生产服务器创建节点或运行修复命令，真实供应商的规划质量仍需自带 Key 验收。

## 验证范围

四协议的请求结构、响应解析、错误处理、权限隔离、加密存储、重启恢复、配置摘要、页面操作及移动布局均使用本地模拟服务和自动化测试验证。未使用真实付费 Key 验收供应商在线返回结果；部署后请用自己的 Key 点击测试。

协议参考：[OpenAI Responses](https://developers.openai.com/api/reference/resources/responses/methods/create)、[Chat Completions](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)、[Anthropic Messages](https://platform.claude.com/docs/en/api/messages)、[Gemini generateContent](https://ai.google.dev/api/generate-content)。
