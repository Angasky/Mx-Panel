# Xray Agent 节点管理 API

v0.3.24 起，创建托管 Xray 节点 / 中转时优先选择在线的新 Agent。配置读取、工具检查、证书检查、配置写入 / 校验 / 应用和流量计数查询均通过认证的 HTTPS 管理通道到达节点，由 Agent 本机执行。不是从浏览器连接 SSH，也不是公开 Xray gRPC API。

## 启用

- 命令接入和 Agent 部署下载 v0.3.24；在面板安装 / 更新 Xray 后创建 root 专用授权文件 /etc/mxioc-agent-xray-api。
- 已有标准 Xray 服务器：在 Agent 管理选择“保留配置升级 Agent”。升级保留凭据和配置，补齐本机 API 授权及 systemd 写目录；无需重装 Xray 或修改已有节点。
- Agent 使用 auto、http 或 websocket 上报模式；管理请求使用单独 HTTPS 长轮询。无需节点开放额外公网端口。Pull 模式暂不使用该通道。
- Agent 窗口显示“Agent API 已连接”或“SSH · 新通道尚未就绪”。未安装 Agent 的 SSH 服务器须先通过 Agent 管理安装新 Agent。

节点须使用标准路径 /usr/local/bin/xray 与 /usr/local/etc/xray/config.json。本机授权文件必须为 root 所有、无其他用户权限的普通文件。删除该文件并重启 Agent 可关闭本机 API。

## 创建与失败恢复

任务只允许固定操作和结构化参数，脚本由 Agent 内置代码生成，不能指定任意命令或程序。每个任务有随机 ID、有效期和 0600 持久回执；执行前记录状态。重复同一任务返回原回执，无法确认的任务不会自动执行第二次。命令与原服务管理共享本机执行锁。

配置仍使用摘要比较、内核检查、原子替换、同步落盘和失败恢复。Agent 只是替换传输路径，不能省去持久化，否则 Xray 重启后节点会消失。当前仍通过服务重启应用配置；没有宣称 HandlerService 无重启热更新。

创建开始时选定传输方式；API 开始执行后超时不自动回退 SSH。面板重启或请求超时按现有创建日志重新核对。凭据撤销、服务器身份变化或错误回执 ID 会拒绝请求。

## 范围和限制

本轮覆盖独立 Xray 的创建链路。sing-box、Web 面板、内核安装、SNI 扫描、证书申请、其他维护操作仍沿用既有通道。证书检查遵守 Agent systemd 文件访问限制，建议使用 /etc 下的证书路径；不放宽 ProtectHome。首次安装 / 升级 Agent 仍需要一次 SSH 或命令接入。

省去 SSH 往返不意味着节点创建零耗时：内核配置校验、计量初始化、服务重启和网络 RTT 仍需时间。不同网络提速程度应实测，不承诺固定倍数。

## 验证

Go 全量测试、专项 race，鉴权 / 撤销 / 任务关联与本机回执权限测试；创建和中转模板通过 API 适配层的断线重试与恢复测试；真实 Xray / sing-box 配置校验；界面六主题四屏宽验证。业务节点不用于试建或删除测试。
