# 默认策略模板（v0.3.19）

进入订阅管理 → 策略模板，点击某个模板的「设为默认」。之后打开「新建订阅」，配置模板来源自动预选该模板，仍可手动改选内置模板或其他自定义模板。复制已有订阅不受默认设置影响。

模板列表标注「当前默认」，可点击「恢复内置默认模板」。删除当前默认模板时，与删除记录一起原子保存回退状态。已创建订阅的节点、策略组、规则、额度和链接不修改；修改模板只影响以后创建的订阅。

本项是管理员统一的新订阅默认策略，不是普通用户个人模板偏好或多套餐管理。设置保存在 profiles.json 的 defaultPolicyTemplate，重启后保留。旧索引缺省为 blank。

## 接口与兼容

- 管理员 GET /admin/api/policy-templates 返回 defaultTemplateId。
- 管理员 PUT /admin/api/policy-templates/default 接受 id 和 expected（读取的旧默认 ID），支持 blank 或现存 policy-* 模板。旧值不匹配拒绝，避免旧页面覆盖新选择。
- 创建订阅可显式提交 templateId="default"，在创建事务内读取默认模板。网页直接提交用户看到的实际模板 ID，避免打开表单后默认设置变化导致套用不同模板。
- 为兼容已有客户端，省略/空 templateId 仍使用内置模板；显式 blank 不被默认值覆盖。
- 普通用户没有默认模板管理权限，沿用管理员认证和同源检查。
