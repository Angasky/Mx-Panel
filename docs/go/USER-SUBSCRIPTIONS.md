# 管理员查看用户客户端订阅（v0.2.34）

入口：设置 → 用户与权限 → 对应用户的“客户端订阅”。管理员可选择该用户获授权的订阅，查看 Clash/Mihomo 地址和现有各客户端格式的兼容报告，复制地址、下载、打开或查看二维码。没有兼容项目的格式显示原因，不提供误导性的下载按钮。

## 权限与行为

- 每次打开、切换订阅或点击“重新读取”，重新读取用户启用状态、授权列表及当前订阅地址。
- 禁用用户的入口不可点击；页面已经打开时，重新读取会拒绝并清空原地址。删除用户、撤销订阅授权或读取失败也清空旧展示。
- 未分配订阅或授权的订阅已删除时，列表显示无可用订阅。指定未授权/已删除订阅返回拒绝。
- 切换时先清除旧链接；弹窗关闭或过期请求返回时不覆盖新界面。不改变当前工作订阅。
- 该入口只有管理员可用，普通用户继续通过自己的订阅门户访问。不是用户模拟登录，不创建登录会话，不修改授权、密码、额度或节点。

地址是订阅的下载凭据，多名用户共用同一订阅时地址相同。禁用用户不撤销已经复制的地址，需要同时轮换订阅链接；已经展示或复制到浏览器的内容不能被远程收回。页面不是自动轮询授权，交付前请重新读取。复制由管理员手动触发，不自动发送 Telegram 或其他消息。

下载仍受原有有效期、流量额度、IP 白名单和浏览器访问规则控制。兼容报告表示格式可转换，不保证当前请求一定获准下载或客户端实际联网成功。

## API

管理员 `GET /admin/api/users/subscriptions?id=用户ID` 返回用户 ID/名称和已授权且仍存在的订阅 ID/名称，不返回下载地址。

附加 `&profile=订阅ID` 后返回该订阅的当前原始地址和各格式兼容报告。响应禁止缓存；不返回用户口令哈希、会话或配置文件路径。不接受写入方法，普通用户与未登录请求拒绝。

## 验证

Go 全量与用户隔离专项 race；覆盖管理员权限、普通用户/未登录拒绝、授权隔离、禁用/删除/撤销、空列表、字段泄漏检查。

真实 Chromium 与隔离 Go 后端验证两个授权订阅切换、复制处理器得到正确地址、特殊字符转义、撤销与禁用后清空旧地址、六主题四宽度。复制测试替换剪贴板处理器记录参数，不宣称系统剪贴板实测。未向实际用户发送链接，未修改生产授权。材料：artifacts/v0234-user-subscriptions。


## v0.2.37：用户列表查找

用户管理支持用户名包含搜索（忽略大小写、搜索词首尾空格）、启用/禁用筛选与每页 20 人分页。搜索和状态筛选组合使用，改变条件回到第一页；刷新及删除后保留条件，最后一页被删空时自动收敛到有效页码。清除筛选恢复全部列表。编辑后返回列表使用默认条件。

筛选只影响展示，不改变用户授权；禁用用户的客户端订阅按钮仍禁用。中文输入法组合输入结束再刷新结果。数据仍由原管理员接口一次读取，分页在浏览器完成，不声称实现后端分页或降低用户接口响应体积。

隔离 Chromium 使用 43 位模拟用户，验证跨页编辑、筛选后的删除和订阅用户 ID、输入法事件、空列表、转义、六主题四宽度；未修改生产用户。


## v0.2.38：按授权订阅筛选

用户列表新增授权订阅选择，可与用户名、启用/禁用状态组合。选择订阅后显示获授权的用户（无论该用户是否启用，除非另选启用状态）。选择“无有效订阅授权”时，包含授权列表为空或仅指向已删除订阅的用户；不依据额度、到期或节点连接判断授权有效性。

条件改变回到第一页，刷新保留条件。刷新发现当前筛选订阅已删除时显示“原筛选订阅已删除”并返回空结果，需主动清除或改选。名称作为纯文本展示，选择使用订阅 ID，不依赖名称唯一。仅过滤管理员列表，不改写授权，不提供多套餐产品逻辑。

Chromium 使用 43 位模拟用户验证组合条件、刷新、删除订阅后的空结果和失效授权归类，复用编辑/删除/客户端订阅目标检查及六主题四宽度验证；不修改生产用户。
