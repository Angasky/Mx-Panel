# 网站信息（v0.2.33）

入口：设置 → 网站信息。管理员可以设置名称、简介和公开公告，普通用户只能看到公开内容。

| 字段 | 限制 | 展示位置 |
| --- | --- | --- |
| 面板名称 | 最多 60 个 Unicode 字符，不允许控制字符或换行 | 浏览器标题、登录页名称、加载页及管理界面的品牌文字 |
| 简介 | 最多 160 个 Unicode 字符，不允许控制字符或换行 | 登录页、管理侧栏 |
| 公告 | 最多 1000 个 Unicode 字符，可含换行与制表符 | 登录页、管理员与普通用户登录后的页面 |

所有内容均公开可读，请勿填入密码、订阅地址或内部信息。保存时去除字段首尾空白；空名称与简介沿用原界面默认文字，空公告隐藏公告区域。不同位置的默认名称仍保留原有 MXIOC / Mx-Panel 文案。

## 预览、保存和恢复

“预览（不保存）”只在弹窗中显示当前输入。HTML、Markdown 和脚本均按普通文字显示，链接不自动转换为可点击元素。长文本自动换行，长公告可在区域内滚动。

“恢复默认内容”清空编辑框并显示预览，点击“保存网站信息”后才生效。保存立即更新当前浏览器；其他浏览器刷新页面后读取最新信息。两个页面同时编辑时，后提交的旧版本返回冲突，需重新打开设置核对后再保存。

此功能独立于“监控分享”中的公开探针站标题、Logo、介绍和配色；不会改变通知模板或浏览器主题。未实现自定义 HTML/CSS、登录背景、公告投递/已读追踪或按角色隐藏公告，不宣称与参考项目的网站定制完全等价。

## API 与存储

- 公开 `GET /site-info`（亦支持 HEAD）：仅返回 name、description、announcement 及非空 logo，禁止缓存，无需登录，不返回账号、服务器或配置版本。
- 管理员 `GET /admin/api/site-info`：返回 config 与 revision。
- 管理员 `PUT /admin/api/site-info`：提交完整 config 和读取到的 revision，沿用管理员授权、HTTPS/本地开发限制及同源写入校验。普通用户不可读写管理接口。
- 配置存储为数据目录下的 site-info.json，采用私有临时文件、同步与原子替换；重启保留。
- 文件缺失时使用空配置；损坏时接口报错，不静默覆盖原文件。新页面的公开信息加载失败时保留默认界面，不阻断登录。公开请求最多等待五秒，加载不阻塞认证。

## v0.2.35：面板 Logo

网站信息设置可上传本地 PNG/JPEG（最多 24 KiB，宽高各不超过 512 像素）。选择后先预览，保存后应用到登录页、加载页及侧栏。图片等比显示，不拉伸；方块主题会移除原背景图以避免叠图。加载页显示取决于公开配置加载速度，不保证首帧出现自定义图像。

“移除 Logo”及“恢复默认内容”仅修改待保存表单，保存后恢复各主题默认图标。未选新文件时保留原图；不合法图片不替换当前预览或已保存图片。上传读取与保存期间有按钮状态保护，移除或重置会使迟到的图片读取结果失效。

后端复用公开探针图片校验器，校验 Base64、实际 PNG/JPEG 格式、完整解码、尺寸和大小；拒绝 SVG、外部 URL、损坏图片及伪造 MIME。图片作为本地 data URI 随 site-info.json 持久化和公开返回，不向第三方图床发送请求。v0.2.36 已加入标签页图标；不包含登录背景或探针站 Logo 同步。

管理 PUT 的 config.logo 为可选字段：省略或 null 保留原图，显式空字符串移除。旧版网页只更新文本时不会擦除 Logo；已有配置没有 logo 时使用默认图标。配置版本仍覆盖全部字段。

验证包含原网站信息全量回归、PNG 边界/伪造 MIME/超限/SVG/外部 URL 拒绝、旧请求兼容、重启持久化、移除及专项 race；真实浏览器完成上传、预览、保存、刷新登录页、错误文件保留原图及六主题四宽度检查。图片使用本地生成的纯色测试图，不涉及生产配置。


## v0.2.36：浏览器标签页图标

面板 HTML 在脚本运行前声明同源 `/site-icon` 图标入口。此入口无需登录，读取当前已验证的 Logo 并按真实格式返回 PNG/JPEG；未设置或配置损坏时返回固定本地 M 字默认 SVG。默认 SVG 不含用户内容，用户上传 SVG 仍然拒绝。读取失败不写回配置，网站信息管理接口仍报告原错误。

Logo 配置加载或保存后，页面将 `rel=icon` 切换为当前图片的 data URI，避免重复使用旧图片 URL。移除后切回带新查询参数的默认入口；接口返回 `Cache-Control: no-store`，旧查询参数不会取回历史图片。无需额外维护一份图标文件，也不支持单独设置 favicon。公开探针页面不增加此声明。

`GET /site-icon` 与 HEAD 支持公开访问，只返回当前图片或默认图标，其他方法返回 405；包含 MIME、长度、nosniff 和限制性 CSP。不向第三方站点发起图片请求，不暴露账号或内部路径。

验证：PNG/JPEG 原始字节、默认/移除/损坏回退、旧 URL 查询参数、HEAD 与方法限制、全量及专项 race；真实 Chromium 检查上传保存后的 favicon 地址、图片解码、移除与刷新，以及原六主题四宽度回归。浏览器标签栏是浏览器自身 UI，自动化检查覆盖图标声明与资源，不宣称所有浏览器收藏夹缓存均会立即更新。
