- 移除服务器只清理当前总控的注册信息、任务与面板会话，解除所有本地订阅的 active / provisioning 绑定。不连接远端，不查询其他总控，不删除节点、用户、订阅 YAML 或已计费用量，离线服务器也可移除。

### 管理员登录会话持久化

- 登录会话以 SHA-256 摘要保存到认证文件的 goSessions 字段，保留未知字段，不落盘 Cookie / Bearer 原文。沿用 12 小时固定有效期及最多 8 个会话，达到上限淘汰最早会话。
- 服务重启读取有效会话；过期记录不恢复，损坏记录与异常有效期拒绝加载。会话绑定完整账号凭据指纹，手工更换账号、盐值或密码摘要后旧记录不再生效。
- 退出登录先持久化撤销，再返回成功；登录写入失败不发放令牌。修改账号或密码与清空会话在同一认证文件事务内完成，避免两份文件提交间中断恢复旧会话。
- 兼容旧认证文件，不继承 Python sessions.json，切换到 Go 首次需重新登录。Cookie 与 Bearer 使用统一提取规则，避免其他 Authorization 头影响 Cookie 退出。
- 测试覆盖重启保留、退出后重启、改密后重启、外部凭据更换、固定过期、会话上限、写入失败、未知字段保留与摘要存储。本版本按单服务进程运行；登录失败限流仍为进程内状态，多进程共享会话和跨重启限流尚待迁移。

### 原生自动证书任务与域名候选

- 原生 POST / GET servers/certificates，沿用 job 包装、202 接收、轮询与错误状态，匹配现有前端；后台任务不依附单个 HTTP 请求，随进程退出取消，最长 290 秒。
- 全局最多四个并行签发、最多 64 条任务记录。同服务器同域名重复请求复用运行任务；在启动前取得服务器操作锁，保护连接资料修改、服务器移除及其他面板写入。任务验证服务器、域名及连接资料代次，跨服务器或换绑后不接管。
- 编译嵌入已在正式后台验证的 Shell 模板，测试检查与 Python 参考脚本一致；原生 Go 使用固定指纹 SSH 执行，不调用 Python。固定 acme.sh 源码提交与摘要、检查 DNS / 端口、安装证书、匹配私钥及配置续期均沿用相同流程。
- 只在证书准备标记和本地关联写入均成功后返回 succeeded。错误返回受限长度并移除 SSH / 面板密码；成功只返回证书路径，不读取私钥内容。certificateDomains 原子保存并展示于服务器信息，重启保留候选；进程内任务不恢复，重试会检查服务器已有证书。
- 支持 ASCII 与 Punycode 域名，Unicode 域名自动转换尚待适配。模板创建入站的 Go 控制器仍待迁移；证书任务就绪不代表现有 Go 服务已经支持完整 HY2 创建工作流。
- 实机复用现有证书时发现多密钥主机的算法选择与旧 Paramiko 不一致，导致 Go 误报指纹变化；已优先协商 Ed25519，并在认证前核对其他受支持的密钥类型。只接受原有指纹，不采用新指纹；匹配后认证失败不尝试其他凭据，不启用 SHA-1 / DSA 主机签名。
- 单元与 HTTP 回归覆盖认证 / Origin、失败轮询、任务取消、重复提交、并发上限、连接改动保护、元数据持久化、任务重启隔离、日志脱敏及多密钥主机的认证顺序。
- 独立 Go 测试进程通过原有固定指纹连接真实节点服务器，复用已签发的自有域名证书，返回 succeeded；没有新申请证书，也没有替换线上正式后台。这轮不重复声称 Go 已完成客户端全链路或完整模板创建验证。

### 客户端链式代理与性能基准

- 原生 POST / PUT chains：复制落地节点的完整参数，设置入口 dialer-proxy，支持策略组选择与改名引用联动。拒绝相同入口出口、已组成链路的节点及无效策略组；镜像、备份、失败回滚与主备保护沿用配置事务。
- 补齐 GET failovers / server-chains 的已有记录读取，供链式代理页正常加载；服务器端中转创建和主备写入尚未迁移，不把客户端链路冒充服务器路由配置。
- 配置与 HTTP 测试覆盖参数保留、重命名、策略组变更、循环拒绝、失败不落盘、认证 / Origin 和前端页面依赖。
- 新增 tools/bench：同机、相同 YAML、30 份订阅、100 / 1,000 节点，三轮交替执行。保留备份和镜像，将真实修改与未变更保存分开；测平均 / P50 / P95、请求吞吐、服务进程 CPU 和采样 RSS。全部 6,336 个计时请求均成功，样本见 docs/performance/2026-11-03。

### 配置缓存与跨重启登录限流

- 原生 YAML 内容摘要缓存与节点快照 JSON 复用：最多 32 份配置，32 MiB 估算准入预算，超出预算时正常读取但不缓存。每次读取仍核对文件内容 SHA-256，不依赖文件大小或修改时间，外部同尺寸 / 同时间修改也会刷新。
- 对外返回和编辑使用独立文档副本；订阅 token、撤销状态、额度、到期与公开资料每次重新读取。真实修改后及镜像失败回滚时丢弃缓存，不以旧缓存掩盖 YAML 损坏或文件删除。
- 保存前精确比较配置，兼容 JSON / YAML 整数类型差异且不经过浮点转换。内容未变且所有镜像完整一致时跳过备份与写入，保留注释和文件时间；镜像缺失或不一致仍执行带备份、fsync 和失败回滚的修复。
- 登录失败记录原生持久化到认证文件 goLoginFailures 字段：维持每 IP / 账号 15 分钟 5 次、最多 4,096 条，键使用 SHA-256 摘要。验证密码之前先持久化尝试，写入失败返回错误；重启保留窗口，正确登录持久化清理对应记录，损坏记录拒绝加载。
- 沿用单服务进程模式，不声称多进程共享限流。认证文件未知字段与既有会话均保留；Go 不恢复 Python 进程内限流记录。
- 回归覆盖缓存副本隔离、外部同时间改写、缓存淘汰与大文件不缓存、实时额度 / token、未变更 JSON 保存、缺失镜像修复、事务错误隔离，以及连续重启、过期窗口、登录成功重置与持久化失败。同一性能脚本三轮复测共 6,336 次请求全部成功，报告见 docs/performance/2026-11-03-optimized：1,000 节点快照 19.84 → 1.56 ms，未变更保存 52.04 → 2.33 ms。小规模真实修改仍慢于 Python，连续写入 RSS 更高，不声称全面超过。

### YAML 写入内存与提交后缓存

- 性能剖析发现固定版本 YAML v3.0.6 的发射器保留全部已消费事件，成为大型写入的主要分配来源。保留上游许可、NOTICE、测试与原文件摘要，只对事件队列做就地压缩，未消费的前瞻事件保持原序。
- 根模块通过显式 replace 引用 third_party/yaml，原解码、格式化和公开 API 不变。上游版本仍固定 v3.0.6，后续升级需要复核或移除本地补丁。内置队列回归在原版稳定失败，修复后通过；完整上游测试和 8 类输出摘要对照通过。
- 仅当所有镜像写入成功并完成 fsync 后，才保存独立的已提交配置副本，避免下一次修改重新解析全文。缓存只接受保守的标量 / 映射 / 列表类型；浮点、时间、自定义类型等退回文件解析，不用猜测自定义 YAML 序列化结果。外部修改仍逐次核对文件内容摘要。
- 回归覆盖落盘结果与缓存一致、整数精度、调用方保留引用后修改的隔离、非标准类型回退，以及镜像失败不发布缓存。备份、镜像、回滚与真实落盘同步维持原行为。

- 写入优化同脚本三轮 6,336 次请求全部通过，报告见 docs/performance/2026-11-03-write-optimized。1,000 节点真实修改 51.41 → 34.85 ms，YAML 保存 67.22 → 48.62 ms，写入场景采样 RSS 下降；部分读取均值及未变更保存尾延迟退步，需继续定位。

### 原生服务器 SNI 与 Reality 批量验证

- 原生 POST servers/sni，沿用现有扫描窗口的 serverId / candidates / force 请求与 results 响应。单批 1–20 个域名，规范大小写和 Punycode 域名、去重；保留现有 42 个内置候选，未扩充列表。
- 每批复用一条固定指纹 SSH 连接，在目标服务器上以 getent 解析，验证全部地址均为公网后，通过 curl 的固定地址连接检测 TLS 1.3 和系统 CA；最多五个并行检查，每目标最多尝试三个地址。控制端和远端均不调用 Python。
- TLS 通过后，原生 Go 生成随机 UUID、X25519 密钥、short-id 和每目标路由配置。一批只启动一对隔离 Xray，回环监听随机高端口；避开现有 TCP / UDP 绑定，端口冲突换一批端口重试一次。等待所有 SOCKS 监听就绪，每目标进行两次真实 Reality 访问，只有认证后取得黑洞 HTTP 403 才通过。
- 临时进程有退出 / 信号清理和 75 秒上限；不写生产内核配置、用户、计量规则或服务。脚本 / 命令输出限量，错误不会返回临时私钥或现有 SSH 密码。服务器需已有 curl / getent / timeout / 系统 CA 和可用 Xray；缺失时返回失败原因，TLS 成功不会被当作 Reality 可用。sing-box 尚无等价验证器，继续不列为可选。
- 每服务器最多两批、全局最多四批、整次请求 160 秒上限；取消会释放控制端名额，远端临时进程仍由信号和独立超时兜底。结果缓存最多 2,048 项，按服务器身份、域名和已核验 IP 隔离，成功 10 分钟、失败 15 秒；强制重扫清理旧记录并实际验证。连接资料变化或服务器移除后丢弃在途结果。
- 回归覆盖 DNS 非公网 / 混合地址、TLS / 证书失败、缺失或重复验证标记、部分结果、工具 / 内核缺失、端口重试、缓存强制失效 / 到期 / 容量、服务器变更、并发名额、取消及 HTTP 鉴权 / 方法 / 参数。Shell 语法检查和现有桌面 / 手机扫描窗口回归通过。
- Windows 本机真实 Xray 隔离测试使用本地 TLS 1.3 服务：两次 Reality 访问通过，错误公钥不通过；不访问公网或生产服务器。该测试通过 MXIOC_TEST_XRAY 显式启用。远端 Linux 整段脚本和生产节点的完整链路验证尚未完成，未替换线上后台。
