# 服务器分组（v0.2.50）

入口：服务器管理 → 服务器列表 → 管理服务器分组。创建分组后，在服务器卡片选择所属分组，或勾选多台服务器、选择目标分组并点击“批量移动分组”。

- 每台服务器归属一个分组，支持 SSH、外部探针同步与 Agent 服务器。新服务器默认未分组。
- 分组筛选支持全部分组、未分组或指定分组，可同时按名称/IP、软件类型、监控状态筛选；显示分组服务器总数。
- “选择本页”仅选择当前页；选择可跨页保留，计数反映所有已选服务器。“取消选择”清空，刷新服务器列表也清空。批量移动作用于全部已选服务器。
- 最多 100 个分组，名称 1–60 字符，支持中文，忽略大小写后名称不可重复。支持改名；删除分组会将成员移回未分组，不删除服务器、节点、订阅或监控数据。
- 分组属于管理分类，不改变普通用户订阅权限，也不自动改变订阅导出或代理分流。

管理员 API：`GET /admin/api/servers/groups` 返回 groups、assignments、revision；PUT 接受 create/rename/delete/assign 操作及 revision。版本冲突返回 409，刷新后重试。批量移动先核对所有服务器和目标分组，不存在的服务器不会导致部分成功。

分组和归属保存在现有 `remote/servers.json`，沿用锁与 0600 原子写入；移除服务器时同时清除归属，普通连接设置保存保留分组。已有完整数据备份包含分组。

验证：Go 全量、分组/移除专项 race、权限与跨站拒绝、并发版本冲突、重启保留、批量原子性、删除保留服务器、删除重接不继承旧分组；隔离真实后端浏览器操作和六主题四宽度。未改动生产服务器分组作验收。
