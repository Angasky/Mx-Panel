# 用户首选客户端（v0.3.20）

普通用户登录订阅中心后可选择首选客户端并保存。偏好保存在账号中，换浏览器、刷新或重新登录仍保留，只影响自己的主要复制/下载按钮。其他格式依然可以展开使用。

每份订阅使用实时转换报告判断可用性：首选格式不可用时明确提示并回退到 Clash/Mihomo，不返回无效转换链接。显示所选格式的转换限制说明。此功能不修改共享配置、策略组、防泄露设置、节点凭据、额度、授权或订阅令牌；不是普通用户自定义分流模板。

普通用户 GET/PUT `/admin/api/portal/preferences` 只读写当前登录账号。PUT 接收 client 与 expected（原偏好），白名单验证格式并检查并发变化，事务内再次确认用户启用及当前会话有效。旧用户默认为 clash；管理员修改账号不会擦除偏好。

测试覆盖双用户隔离、匿名/跨站拒绝、非法格式、版本冲突、恢复默认、落盘读取和门户字段；真实浏览器验证保存/刷新、主要下载链接、格式不可用回退以及六主题四宽度。使用隔离测试账号，未修改生产用户偏好。
