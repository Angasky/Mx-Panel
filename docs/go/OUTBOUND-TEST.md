# 实际代理出站测试

v0.3.27 新增三个入口：

- 节点管理：单节点“实际代理测试”，以及选中节点 / 全部节点的批量测试（每批最多 30 个）。
- 服务器节点：“服务器出站测试”，读取当前配置的出站标签，单批依次测试。
- 创建中转：落地选择已有订阅节点或分享链接后，可在创建前测试；选择尚未创建的新落地时不提供虚假的预检测。

测试从所选独立 Xray 或 sing-box 服务器发起，经目标出站访问固定 HTTPS 检测地址。可选 Google Gstatic、Google 和 Cloudflare 的 generate_204。仅 curl 成功且 HTTP 204 才标记可用。显示的是完整 HTTPS 请求耗时，不是 ICMP ping。

临时内核使用仅回环监听、随机账号密码的 SOCKS 入口，不配置直连回退。运行使用独立临时目录，结束或超时后清理；不保存业务节点、不改业务配置、不调用 systemctl 重启业务内核。批量任务逐项显示结果，单项错误后继续；停止或关闭窗口后不再提交下一项。在途测试有 12 秒请求及 25 秒内核上限。

接口仅管理员可用。返回标签、协议、状态和耗时，不返回分享链接、密码或原始内核日志。客户端代理链、引用其他出站的 detour / proxySettings / dialerProxy 不能当成单个出口测试，会明确拒绝。不支持的节点协议 / 参数遵循原有严格转换规则，不会静默丢弃参数后冒充通过。

检测站点失败不等于该节点所有应用都不可用，可换另一个站点对照。此次不做 UDP、带宽、手机本地网络或完整复杂路由测试；sing-box 自定义多文件布局中的外部依赖也可能需要单独适配。

验证包括：真实 Xray 与 sing-box 经认证 HTTP CONNECT 出口到隔离 TLS 站点，正确凭据通过、错误凭据失败；非法目标、状态码、NaN/Inf/超时结果拒绝；HTTP 鉴权和 CSRF；浏览器订阅批量、服务器标签批量、创建前测试、关闭后停止后续项，以及六主题四屏宽。Aws-HK 的已有 direct 出站实测 HTTP 204，测试前后配置摘要与业务 PID 一致。
