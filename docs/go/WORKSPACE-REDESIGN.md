# v0.3.0 工作区重新设计与验收

## 设计依据

采用 [leonxlnx/taste-skill](https://github.com/leonxlnx/taste-skill)，读取 `skills/taste-skill/SKILL.md`（design-taste-frontend 2.5.1），来源提交 `f6b76575f949707b4e3c37cd86cb44b0b98643e8`。

将其统一设计系统、内容层级、真实界面、对齐、交互反馈、键盘焦点及浏览器验收原则应用于实际管理软件。保留本地 Inter 与 Noto 中文字体，不增加外部字体请求。深色采用石墨与橙色；默认浅色采用蓝色操作强调，另有简约、粉色、琥珀和我的世界主题，保留后者立体按钮。

该 skill 的整屏宣传页、照片、hero 和展示动画要求不适用于高密度管理控制台。按照用户完整重设计管理应用的目标适配，不增加无关宣传章节。后端业务与权限沿用现有实现。

## 页面与操作

- 左栏按订阅与用户、服务器与监控、节点与路由、系统设置组织；当前分区展开，移除重复的顶部二级导航。
- 固定工具栏显示当前订阅、刷新与退出；功能/订阅搜索支持 Ctrl/Cmd+K、方向键、Enter 和 Escape。
- URL hash 支持直接打开页面及浏览器前进后退；分页可直接输入页码。
- 工作台提供配置节点、服务器和订阅链接入口，可点击统计指标；客户端链接卡片双列，窄屏单列。
- 服务器、订阅和节点支持列表/卡片切换；筛选器有可见标签；节点批量操作默认展开。
- 添加服务器统一选择 Agent 命令、SSH、已有面板/内核、探针。服务器表单划分身份、SSH 验证、面板与内核。
- 表单编辑使用侧边抽屉，复杂配置增加目录和固定操作区。保留现有字段与保存行为。
- 原生 confirm/prompt 共 71 处改为统一异步对话框，40 处 alert 改为信息窗口。支持取消、Escape、焦点恢复，页面上下文变化时不继续确认；不移除后端操作确认要求。
- AI 可在整页和浮窗使用；离开整页恢复悬浮入口。修复隐藏控件被缩放定位到左上角遮挡手机导航；未自定义位置时入口保持右下角，拖动与键盘移动位置可保存。
- 登录、普通用户订阅门户、公开监控采用同一排版体系；公开监控支持名称搜索、状态筛选、计数和手动刷新。
- CSS/JS 嵌入 Go 二进制，无需额外安装前端依赖；四个资源提供 GET/HEAD，其他方法返回 405，使用 no-cache 重新验证。

## Skill 自动检查的适用边界

实际执行了 skill finish gate，对隔离服务登录页检查。第一轮 14 项失败，修复缺少主标题、焦点轮廓及错误 motion 标记后，第二轮仍为 `GATE: FAIL 11`，没有宣称通过。

剩余项包括英文分类词 `panel` 与中文标题匹配、展示型 moment、hero 整屏、章节高度/留白/标题/边缘/行/分栏以及 `.wrap` 结构要求。它将登录表单视为营销网页，这些要求未机械套用。未修改检查器、未隐藏受测页面，也未用豁免掩盖结果。管理应用的实际布局与交互以以上浏览器矩阵验收。

不包含真实远程服务器内核安装、节点拨测、付费 AI 模型请求、通知发送或 arm64 实机运行。没有据此声称所有外部功能均已实机验证。
