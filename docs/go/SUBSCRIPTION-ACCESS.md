# 订阅 IP 白名单（v0.2.8）

入口：**订阅管理 → 订阅 IP 白名单**，或设置中的同名入口。仅管理员可读取和修改；每个订阅独立保存，默认关闭。

## 使用

1. 选择需要限制的订阅，开启白名单。
2. 每行填写一个 IPv4、IPv6 或 CIDR 网段，最多 64 项。支持加入界面显示的当前 IP；保存时会规范化网段并去重。
3. 点击「校验并预览」，确认当前识别地址是否在允许范围内。预览不会保存配置。
4. 保存后对下一次下载立即生效。当前地址未获允许时会再次提示确认，但不会阻止管理员配置其他设备的地址。

关闭限制会保留地址列表。限制不影响面板登录，因此可随时返回设置关闭。手机网络、家庭宽带、VPN 出口变化都可能导致订阅更新被拒绝；请按实际下载出口配置，而不是节点服务器的 IP。

## 覆盖范围

所有 `/sub/<token>` 和 `/convert/<token>/<format>` 公共下载（包含 GET/HEAD）使用同一检查，在读取节点配置、导出和返回流量头之前拒绝未授权地址。被拒绝时返回 403，不返回节点凭据、订阅标题或流量信息；未知订阅仍返回 404。正常响应和拒绝响应均禁止缓存。

限制的是订阅下载，不是 VPN 内核的连接 ACL；已经导入的节点配置和现有连接不会因此失效。若链接或节点凭据已经泄露，仍需执行相应凭据轮换。管理员的配置编辑和兼容报告不受下载限制。

## 反向代理与 Cloudflare

直连使用 TCP 连接来源，不信任客户端提交的 `Forwarded`、`X-Forwarded-For`、`CF-Connecting-IP` 或 `X-Real-IP`。

仅在启动时已开启 `TrustLoopbackProxy` 且直接连接来自回环地址时，读取反向代理覆盖生成的单个 `X-Real-IP`。缺少、重复或格式不正确时无法识别访客；开启白名单的订阅会拒绝访问，不退回代理地址。

仓库的 Nginx 示例使用 `proxy_set_header X-Real-IP $remote_addr`。内置 HTTPS 网关从 v0.2.8 起也覆盖该头，并去除客户端伪造的 Cloudflare 地址头。Docker/OpenRC 使用内置网关时，升级应用和网关进程后再启用本功能；自建代理必须遵循同样的覆盖规则，不得直接转发客户端输入。

Cloudflare/CDN 前置时，需要在 Nginx 等边缘代理配置仅信任供应商实际出口网段的真实 IP 恢复，再把恢复后的 `$remote_addr` 传给应用。不要信任全网提供的 `CF-Connecting-IP`，也不要把所有 CDN 出口网段放进白名单来替代访客限制。面板不自动修改你的 CDN 或 Nginx 信任配置。

## 持久化与验证

配置保存在订阅索引的 `subscriptionAccess`，随面板数据备份和恢复。修改使用现有索引原子写入；关闭时保留列表，损坏配置不会自动降级成无限制访问。

已验证：IPv4/IPv6/IPv4 映射地址、CIDR 掩码与去重、非法输入与空名单、重启读回、无效修改不覆盖、配置损坏拒绝、原始订阅和转换格式统一保护、HEAD 无正文、流量头不泄露、伪造代理头、内置网关真实代理请求、匿名/普通用户/跨域拒绝，以及六主题四宽度浏览器的预览/保存/关闭/取消操作。测试使用隔离订阅，不对生产订阅启用限制；CDN 实际访客地址恢复仍须按部署核对。
