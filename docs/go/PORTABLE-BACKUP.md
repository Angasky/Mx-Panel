# 订阅配置加密备份（v0.2.18）

入口：管理员「账号与备份 → 配置备份与恢复 → 加密下载 / 上传恢复」。先选择要操作的订阅，使用独立备份密码下载 `.mxbackup` 文件；密码至少 12 个字符、最多 256 字节，需要再次输入确认。密码不写入面板文件或日志，丢失后无法找回。

## 内容与范围

文件仅包含原始订阅 YAML、订阅显示名称、备份格式版本和 UTC 生成时间。YAML 中的节点密码、DNS、规则、策略组以及原有扩展字段一并加密；不对内容做脱敏或改写。名称和时间也在密文内。导出不触发任何远程连接。

不包含订阅索引/访问令牌、额度、用户、服务器绑定、SSH 凭据、面板登录凭据、全局设置、面板额外安全覆盖、监控历史或证书文件。YAML 本身若包含内嵌凭据、链接或本地文件路径，这些文字仍会包含在备份中，但不会读取引用文件。它不是整机迁移包，也不是 SQLite/PostgreSQL 数据库备份。完整备份仍需保留原数据目录及账号文件。

当前限制：原始 YAML 最多 768 KiB，编码后的明文 JSON 最多 1 MiB，上传文件最多 1 MiB + 128 字节。特殊字符转义可能使明文 JSON 提前达到限制。格式为本项目专用，不导入妙妙屋或其他项目的备份。

## 恢复步骤

1. 选择目标订阅，上传 `.mxbackup`，输入文件密码。
2. 点击「解密并预览」，核对备份来源、时间、覆盖目标及节点/策略组/规则数量；此时不写入。
3. 勾选确认覆盖，再点击「确认恢复配置」。

恢复会验证 YAML、引用关系、主备链路保护，以及预览时的目标配置版本；预览后文件、目标 YAML 或相关元信息发生改变时须重新预览。选择不同订阅可将配置恢复到该订阅，但原绑定与额度不会随之迁移；这可能改变用户收到的节点内容，请核对目标。

沿用原配置写入机制：有变化时先生成本地 YAML 快照，再更新配置镜像，写入失败尝试回退；旧快照仍按全局最近 100 份保留。内容完全相同时不重复生成快照。重复提交旧预览不能覆盖随后发生的新修改。恢复成功后原订阅地址保持不变，不触发远端节点创建、重启或同步。

## 文件格式与验证

版本 1：固定文件头 + 16 字节随机盐 + 12 字节随机 nonce + AES-256-GCM 密文。采用 scrypt N=32768、r=8、p=1 派生 32 字节密钥；文件头、盐及 nonce 作为附加认证数据。每次导出使用新随机数。密码错误、头部/密文被篡改、截断或追加字节均拒绝解密。服务端固定派生参数，不能通过文件指定高资源参数；同一面板同时只处理一个导入/导出请求，额外请求返回 429。

管理员登录、HTTPS、同源校验沿用管理接口；普通用户不可调用。解密内容只在当前请求中处理，预览接口不返回 YAML 或密码，不提供原始服务器路径。密码需经 HTTPS 发给面板处理，不是纯浏览器端加密；不要复用面板登录密码。

验证覆盖：随机化与篡改检测、错误密码、大小/格式限制、跨订阅/跨实例恢复、只读预览、过期预览拒绝、主备保护、镜像失败、恢复前快照、重启与并发、用户隔离和同源限制。真实 Chromium 完成下载再上传、错误恢复、勾选确认、窗口切换后的迟到响应隔离，以及六主题四种屏幕宽度检查。全部使用临时订阅数据，未恢复生产配置。
