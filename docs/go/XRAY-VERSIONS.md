# Xray 安装版本（v0.3.14）

默认安装 Xray 26.6.27。单台“安装 / 更新服务器”提供版本输入选择，可选 26.6.27、26.10.31，或手动填写官方版本号，例如 `26.9.30`（也接受前导 `v`）。只允许数字三段版本号，不接受下载地址、latest 或脚本。

单台确认创建安装任务时保存所选版本，后续安装复用。批量编辑勾选“修改 Xray 安装版本”可统一设置，再执行批量安装；预览展示每台目标版本。未设置的旧服务器默认使用 26.6.27。版本设置仅影响 Xray，不修改 sing-box 的版本。

安装包固定从 XTLS/Xray-core 官方 Release 下载。默认版 amd64/arm64 使用内置 SHA256；自定义版获取同一官方 Release 的 `.dgst` 校验文件，严格提取 SHA256 并校验压缩包，再检查内核报告的版本和现有配置。版本不存在、校验缺失或配置不兼容时停止，不绕过验证。沿用原安装器的备份及失败回滚。

自定义旧版本不保证支持当前所有模板或已有配置，新版 Reality 的客户端要求也可能不同；安装前的实际配置校验决定能否应用。面板版本更新不等于自动升级服务器内核。

验收包含默认和自定义版本参数、非法输入拒绝、记录保存、默认 amd64/arm64 安装器、自定义 digest 成功/失败、校验/配置/服务失败回滚、浏览器选择/取消/提交/批量设置/移动布局。此次另对现有 6 台服务器逐台确认运行中的二进制为 26.6.27、服务 active、配置验证通过；其原内核和配置保存在各服务器 `/var/backups/mxioc-xray/`。
