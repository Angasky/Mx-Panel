# 独立探针页外观（v0.1.23）

管理员进入「设置 → 监控分享 → 探针站外观定制」。支持：

- 标题（最多 60 字）和介绍（最多 200 字），支持中文和英文；留空使用原默认内容。
- 本地 Logo 上传和移除：PNG/JPEG，24 KiB 以内，最大 512×512。图片嵌入配置及页面，无需第三方图片主机，不支持外链、SVG 或脚本。
- 暖橙、云白、深色、我的世界方块四种公开页配色；与后台当前主题独立。
- 隐藏地球视图，仅显示服务器资源卡片。
- 已开启无凭据公开访问时，提供「打开公开探针页」入口。

保存外观不会轮换访问令牌或改变授权规则。仍需选择服务器、填写公开名称、显式启用分享。任何有权访问分享页/API 的人都能看到外观内容；不得填写私密信息。状态 API/WebSocket 的 appearance 字段包含外观设置。暂停、撤销和轮换凭据仍按原规则生效。

旧版配置自动保留默认样式；旧客户端未提交 appearance 字段时不会清空已有外观。输入文字由模板转义，Logo 同时校验 MIME、图片解码、尺寸和大小，公开页 CSP 只允许本地 data 图片。

同时修复通用弹窗滚动位置残留：重新打开回到顶部，滚动预留标题栏空间，避免控件被遮挡。

v0.2.9 新增独立入口：可把域名首页设为公开探针页，并设置 /status/名称 自定义路径（名称为 1–48 位字母、数字、下划线或短横线）。入口必须同时满足分享启用及公开访问权限；暂停、撤销或切回私有时返回不可用。关闭首页选项恢复原登录首页；/admin/ 始终保留，避免锁死管理员。旧版客户端未提交 entry 字段时保留原入口设置。保留 /sub/status-public、凭据链接与 API。此功能不会修改域名、DNS 或反向代理配置，不提供禁止 /admin/ 登录的选项。公开页方块配色为轻量样式，不包含后台主题全部装饰与动画。

验证：后端测试覆盖格式校验、恶意输入、持久化、旧客户端兼容；真实 Chromium 覆盖上传/移除、标题转义、四主题三个宽度、地球隐藏、旧链接继续可用、私有字段隔离与撤销。测试只使用临时服务器记录，不连接真实节点，也未开启生产公开分享。

新增验证：默认首页兼容、首页/自定义路径 GET/HEAD、HTTPS 限制、暂停与私有切换拒绝、旧路径失效、配置损坏时管理入口仍可用、旧客户端设置保留、保留路径拒绝，以及六主题四尺寸浏览器表单与链接验证。未替用户开启生产公开分享。
