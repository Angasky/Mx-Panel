# 套餐默认流量重置日（v0.2.42）

入口：流量与到期 → 套餐模板 → 新建/编辑 → 默认流量重置日。

- 沿用套用日期（resetDay=0，默认）：保留原有周期锚点与时刻逻辑。
- 每月固定 1–31 日：UTC 00:00 为周期边界；北京时间为当日 08:00。月底没有指定日时取最后一天，下月仍使用原指定日。例如 31 日在二月取 28/29 日，三月回到 31 日。
- 一次性总流量不支持固定重置日，表单禁用选择并保存为 0。

修改模板不会自动影响已经套用的订阅，需手动重新套用。重置周期与日期相同则保留下一次重置时间；更改日期或切换周期则从当前时间安排严格未来的边界。保留当前已用量与既有到期时间，不因为改日期直接清零或续期；已到原周期边界时仍先执行原有用量结算和到期重置。

固定日期首次套用可能形成不足一个月的首周期，不按天折算流量或费用。超过日期后，后台按照已有采样/检查周期执行，不能保证在 00:00:00 精确触发。停机错过多个周期时只重置一次，下一次推进到当前时间之后，不累积未使用额度。已到期订阅不因周期重置恢复可用。

重置继续使用原有上传/下载、原始用量清零和远端计数基线标记，防止旧累计值重新计入；不修改远端节点身份、订阅链接或用户授权。模板说明和订阅状态显示 resetDay 与 nextResetAt。

API：套餐模板 PUT /admin/api/traffic/plans 增加 resetDay 整数 0–31，缺省为 0；resetPeriod=none 时只能为 0。已有模板缺少该字段保持原行为。模板保存沿用管理员权限，实际套用使用现有套餐接口。

验证：Go 全量和套餐/周期专项 race；固定日、短月、闰年、跨年、精确边界、重复执行、停机跨周期、到期不重置、用量/有效期保留。真实 Chromium 验证新建/编辑/保存/套用及六主题四宽度。测试采用隔离数据，没有修改生产套餐或真实用户额度；远端用量结算仍受已有采样能力限制。
