# 订阅连接与 IP 城市

管理员选中订阅 → 流量与有效期 → 查看订阅连接 / IP / 城市。

当前适配总控托管的独立 Xray、scope=user 的独立认证用户。通过固定 SSH 指纹的连接读取本机 StatsService 的 statsonlineiplist，先核对入站、用户凭据和计数归属，并在采集后复核配置。不会把订阅下载、系统端口连接数或流量增长当作在线人数。

内核需要支持 statsonlineiplist，并在用户策略级别中开启 statsUserOnline。窗口提供显式启用按钮：需确认，启用同一策略级别的用户在线统计并重启内核，可能短暂中断连接。使用已有配置校验和失败回滚流程；不会因为打开窗口就自动修改节点。旧内核或尚未建立在线映射时可能返回不可用，而不是零在线。

显示去重后的已观测 IP、每个绑定的 IP 和内核报告的最近时间。同一出口 IP 可对应多人，同一人可有多个 IP；不等于精确人数或 TCP 连接条数。在线判定取决于远端内核版本。存在失败绑定时仅代表部分结果。单次最多读取 64 个活动绑定，总超时 45 秒，只在点击刷新时读取。

3x-ui/x-ui/x-panel、sing-box、专属整端口绑定和外部导入节点暂不支持。只持有分享链接无法获取远端认证连接者信息。

城市查询独立点击并确认后，将选中的公网 IP 发送给 https://ipwho.is/，返回国家/地区/城市。未点击时不发送；内网 IP 不查询。城市为近似定位，不代表住址。查询服务不可用不影响 IP 展示。

接口仅管理员可用，普通用户与公共订阅/监控页面不暴露连接 IP；响应 no-store，不持久化连接历史。默认不为真实用户服务器开启在线统计。

测试：独立本地 Xray 26.10.31 真实 VLESS 连接与断开，在线 IP 及时间返回正确；Go 全包与相关竞态测试；浏览器空订阅真实后端、受控 IP/城市响应下的交互、转义和手机布局。未在生产用户节点执行重启或配置变更。
