# 仓库整理与中文搜索修复

用户要求定制版仓库只发布 Go 实现及运行所需文件，测试与开发基准留在本地。

- 当前分支移除旧 Python 后端、requirements、Python 安装器、旧服务文件、测试源文件及开发基准工具的 Git 跟踪；本地备份和历史提交保留。
- 根安装入口改为构建 Go 安装包；反代示例改为 Go 监听端口；README 指向 Go 构建、安装及真实验收边界。
- 内核兼容构建工具改用 Go，可核验固定源码及补丁摘要，不再依赖 Python。
- CI 仅构建和静态检查，移除已不随仓库发布的测试脚本依赖，不声称 CI 做了全功能测试。
- 中文输入法组合阶段停止搜索重绘，组合完成后过滤，过时页面回调作废；三种主题统一系统无衬线字体及中文后备字体，代码/日志保留等宽显示。
- 旧 Python 仓库只同步网页修复，继续作为独立旧版本维护。

浏览器实际覆盖：两个仓库 × 三种主题，拼音组合超过搜索延时不换输入框，确认中文后正确筛选，英文大小写匹配正常。测试与日志保存在本地 artifacts/nov08-ime-fonts.*，不上传测试文件。

GitHub 语言比例来自默认分支的文件统计，不代表迁移行为完整性。仓库去除 Python 文件不等于真实面板、SSH、systemd、公网客户端验收全部完成。已有提交历史不重写。
