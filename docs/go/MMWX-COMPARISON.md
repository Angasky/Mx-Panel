## 验证

暖橙主题经过真实 Chromium 页面、弹窗与 390px 手机布局检查；协议筛选与 sing-box 下载经过真实 Go 后端浏览器验证。生成的 sing-box 配置通过本地 1.14.4 内核 check，未代表所有第三方客户端版本均完成实机连接验证。

多用户经过两个不同账号的真实浏览器登录、订阅隔离、手机布局和管理员管理表单验证；后端测试覆盖管理接口越权拦截、授权变更/禁用/重置/删除后的会话撤销、重启持久化、会话到期与损坏数据拒绝认证。

历史监控与订阅计费分开：只有启用后的有效采样区间计入网卡流量。重启、计数器回退、网卡变化、超过 90 秒的采样间隔、失败样本与跨 UTC 日期区间不计算流量差值。不会伪造安装前或停用期间的历史。

## 补齐顺序与历史安排

1. **已交付第一批：通知中心**。管理员设置 Telegram、按需开启，配置阈值，查看投递记录；加密凭据、持久化去重、限流退避，详见 [通知说明](NOTIFICATIONS.md)。
2. **已补齐第二批：通知扩展**。前一 UTC 自然日网卡观测流量汇总、管理员只读预览、TCP/ICMP 延迟与失败/丢包告警及恢复。下一优先级为续费回调与 Agent 分批升级。
3. **随后：使用与部署能力**。独立探针标题/Logo/介绍/配色已完成；Docker Compose/Alpine OpenRC 已在 v0.1.28 加入；接下来是服务器计费周期与外部订阅流量聚合。
4. **长期架构项**。数据库驱动切换、跨内核连接统计、全部客户端规则/链路转换、三网回程；需要单独设计与实机验收。商业授权体系暂不列入优先项。

通知测试覆盖配置权限、凭据脱敏/加密、连续失败与过期采样、恢复/去重/重启、流量与到期条件、Telegram 成功/429/403/无效响应与重试队列。浏览器覆盖六主题、三种宽度、保存/清除 Token、普通用户读写禁止。测试仅使用隔离数据和模拟 Telegram，未向真实会话发送消息。


v0.1.25：新增按订阅保存的安全与兼容设置（STUN/WebRTC、DNS 防泄露、国内真实 IP、IPv6、广告组默认策略），以及可选实验性 Xray 单节点完整 JSON 导出和 sing-box 导出开关。上述防泄露覆盖仅作用于完整 Clash/Mihomo YAML；跨客户端完整规则转换仍未完成，详见 [订阅安全与兼容](CLIENT-OPTIONS.md)。

### v0.1.30：外部订阅流量汇总

### v0.1.31：服务器快速续费登记

补齐管理员网页的「我已续费」日期预览、确认登记、防重复提交和服务商链接；取消通知队列中已失效的旧到期提醒。不会实际支付，不重置流量，不延长用户订阅；Telegram 内联按钮回调仍待实现。见 [快速续费说明](SERVER-RENEWAL.md)。

### v0.1.32：外部订阅自动刷新

新增每来源 1/6/12/24 小时定时采集，默认关闭；失败退避、持久化计划、后台结果与手动修改冲突保护。补齐无需网页打开的流量快照采集；停机缺口不补算，额度仍取决于上游响应头。见 [外部订阅流量](EXTERNAL-TRAFFIC.md)。

### v0.1.33：Agent 保留配置升级

新增单台 SSH 升级入口，使用固定 Agent v0.1.32 发布包及 SHA256；保留配置/服务文件，备份旧程序，启动失败尝试回退。尚未实现滚动批次与新版本心跳验收；不将远端进程启动视为连接成功。见 [Agent 说明](AGENT-AND-PROBE.md)。

### v0.1.34：Agent 分批编排

新增最多 20 台的串行升级，首台完成新上报验证后等待管理员验收，后续逐台推进。失败/超时/身份变化停止，重启不自动重试。Pull 和版本心跳证明未支持，未做真实生产多机升级验收。详见 [Agent 说明](AGENT-AND-PROBE.md)。

### v0.1.35：Agent 版本确认

WebSocket、HTTP、Pull 均上报编译版本，管理员 Agent 接入页显示版本；旧 Agent 无字段显示未知。升级目标固定至 v0.1.35 并校验 SHA256，分批推进必须同时满足任务成功、完成后新采样、身份一致及目标版本相符；错误或缺失版本等待最多 3 分钟后停止。单台任务页也不再把旧缓存连接误判为升级后确认。版本为经凭据认证的 Agent 自报，不是硬件远程证明；Pull 批次与真实多机验收仍未完成。

### v0.1.36：Komari 接入与导航细分

新增探针服务器列表读取和通过原 Agent 授权独立 SSH 密钥接入，保留两边管理；并非双向节点配置同步或替代 SSH。左侧改为可折叠功能分组。具体要求与验证范围见 [探针同步](PROBE-SYNC.md)。

### v0.1.37：批量接入与监控复用

Komari 服务器可一次确认批量授权，后台自动核对；关联服务器硬件与 24 小时历史直接读取原探针并缓存，不重复采样或保存历史。原探针缺少的明细不额外采集，流量周期与采样告警仍由原探针负责。见 [探针同步](PROBE-SYNC.md)。

### v0.2.12：sing-box 逻辑组合规则
