# 妙妙屋X 功能对照与实现记录

参考仓库：https://github.com/iluobei/miaomiaowuX ，检查提交 `047f92c79985e135fe74a87eab0c44f0e55b6bc6`。

该公开仓库包含 README、安装脚本与配置模板，没有产品前后端源码。README 声明 MIT，但未提供独立 LICENSE 文件。本次未复制其程序、配置模板、图片或品牌资源。X 的截图链接返回 404；视觉参考来自其明确标注的上游 https://github.com/iluobei/miaomiaowu 的公开节点管理截图，不能代表 X 当前版本全部界面。

| 功能 | Mx-Panel 对照结果 |
| --- | --- |
| 多服务器、远程部署、入站、套餐、证书与节点同步 | 已有对应功能，仍需对照每个细节，不能称完全等价 |
| 浅色主题 | 新增原创暖橙主题：暖白、珊瑚橙、灰褐描边和轻硬边阴影 |
| 节点按协议分类 | 新增协议筛选按钮及数量，与文本搜索叠加，全选仅作用于当前可见节点 |
| sing-box 客户端导出 | 新增 mixed 本地代理与手动节点选择配置，复用经过验证的转换器；不转换 Mihomo 规则/策略组/链路；不兼容节点明确跳过 |
| Surge / Loon / Quantumult X / Stash / Surfboard / Egern | 尚未增加独立适配器，不能把通用链接当完整支持 |
| 管理员/普通用户和权限隔离 | 已实现单管理员 + 多普通用户；按订阅授权、禁用、密码重置、删除及会话撤销；普通用户只有订阅门户读权限 |
| Agent WebSocket / HTTP / Pull | 待实现；当前使用 SSH 与面板接口管理，不能等同 Agent |
| 30 天历史流量、24 小时探针历史 | 新增按服务器启用的后台 SSH 采样：24 小时 CPU/内存/网速曲线、30 个 UTC 自然日的网卡流量观测；缺口不补算，不等同完整订阅计费或公网探针 |
| 公开探针站与授权 API | 待实现访问控制与字段白名单，当前不公开生产监控信息 |
| SQLite/PostgreSQL、多种数据库备份 | 架构不同，当前文件持久化与配置备份，不宣称支持数据库切换 |

这是一份待办与已实现记录，不是“全部功能已补齐”的声明。Agent、公开探针与其他客户端格式仍需独立实现与验收。

## 验证

暖橙主题经过真实 Chromium 页面、弹窗与 390px 手机布局检查；协议筛选与 sing-box 下载经过真实 Go 后端浏览器验证。生成的 sing-box 配置通过本地 1.14.4 内核 check，未代表所有第三方客户端版本均完成实机连接验证。

多用户经过两个不同账号的真实浏览器登录、订阅隔离、手机布局和管理员管理表单验证；后端测试覆盖管理接口越权拦截、授权变更/禁用/重置/删除后的会话撤销、重启持久化、会话到期与损坏数据拒绝认证。

历史监控与订阅计费分开：只有启用后的有效采样区间计入网卡流量。重启、计数器回退、网卡变化、超过 90 秒的采样间隔、失败样本与跨 UTC 日期区间不计算流量差值。不会伪造安装前或停用期间的历史。
