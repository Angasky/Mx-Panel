# 服务器列表筛选（v0.2.32）

入口：服务器管理。可同时按名称/IP/域名搜索、内核类型和监控状态筛选；状态数量基于当前搜索与类型条件，修改条件重置第一页，清除筛选恢复全部列表。刷新保留条件，列表为空不代表服务器被删除。

## 状态含义

| 状态 | 含义 |
| --- | --- |
| 采样正常 | 已登记 Agent 的有效心跳在 90 秒内，或历史监控最近 120 秒内成功采样 |
| 采样失败 | 已启用历史监控最近 120 秒内的最后一条采样失败 |
| 采样过期 | 最后观测超出上述时限；不会把历史成功一直显示为正常 |
| 等待采样 | 已启用 Agent/历史监控，但还没有对应有效记录 |
| 未监控 | 没有启用 Agent，且历史采样关闭；不据此判断服务器离线 |
| 外部探针 | 已关联 Komari，需打开硬件监控查看原探针状态 |
| 状态未知 | 数据读取失败、服务器连接信息与 Agent 登记不符或时间异常等 |

界面同时显示来源、观测时间和整批快照时间。原安装进度保留，和监控状态分别展示。刷新是读取已有观测，不是实时连通性测试；页面不自动轮询。代理内核停止、端口不可达或认证失败时，Agent 心跳仍可能正常，因此不能把“采样正常”理解为代理一定可用，也不能把一次采样失败当作离线。

Agent 优先于历史记录；校验当前启用状态、凭据摘要和登记的连接信息版本，轮换后旧心跳不可复用。Pull 仅使用已有本地心跳，不因打开列表主动拉取。外部探针不复用可能遗留的本地历史。单台历史文件读取失败只影响该台；Agent 登记文件损坏时无法可靠确认来源，非外部探针显示未知。

## 接口与边界

新增管理员 `GET /admin/api/servers/observations`，返回 generatedAt 及按服务器 ID 索引的 status/source/sampledAt。普通用户和未登录请求不可读取，响应禁止缓存，不返回主机地址、凭据或原始错误详情。

新增接口只读取本地 Agent 快照和历史文件，不发起 SSH、Pull 或 Komari 请求，不修改采样开关、不裁剪/写入历史、不启停服务。旧列表接口原有的探针地域读取行为不变。未接入所有来源的统一在线连接统计，本项只缩小参考项目“在线/离线筛选”的日常筛选差异，不宣称两者状态定义等价。

## 验证

后端覆盖时限边界、失败/过期/等待/关闭、未来时间、凭据轮换、登记版本变化、配置损坏、权限隔离及旧历史只读保留。Go 全量与专项 race 通过。

真实 Chromium 使用隔离后端登录及空列表接口、模拟的 63 台服务器与七种状态，验证搜索/类型/状态组合、计数、分页重置、失败后清空旧状态及刷新恢复、特殊字符转义、六主题四宽度。未连接生产服务器或修改生产配置。验证材料在 artifacts/v0232-server-filters。
