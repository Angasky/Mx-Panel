# 服务器位置 · 3D 地球

管理员入口：服务器监控 → 3D 地球。先到服务器详情 → 地域与续费，手动填写纬度与经度；两项需同时填写或同时留空，范围分别为 [-90,90] 和 [-180,180]。零坐标有效。v0.1.40 起，未填坐标的探针服务器会复用原探针国家/地区参考位置，标明为近似位置；未能识别地域的服务器列在缺失名单中。手动坐标优先。

支持鼠标/触屏拖动、方向键、左右旋转、位置列表定位、复位及暂停。遵循系统“减少动态效果”；页面不可见或图形离开视口后停止自动绘制，关闭弹窗时释放动画和监听器。无 Canvas 的浏览器保留文字位置列表。海岸线随 Go 程序打包，不从外部地图/CDN 获取资源，也不向第三方查询服务器 IP。

位置来自管理员标记或探针国家/地区参考坐标，不表示服务器在线、线路质量或代理连通。海岸线是 1:110m 概览精度，不用于精确地理测绘。

经纬度默认仅管理员可见。仅当服务器已加入监控分享且“公开这些信息”开启时，公开页面/API 才包含坐标；地球使用公开名称，不包含内部 ID、主机或凭据。更新已公开的坐标会在表单中再次提示确认。关闭公开开关或清空坐标后，后续响应不再包含位置；已经取得的公开数据无法收回。普通用户没有管理坐标接口权限。

现有元信息接口新增可选 `latitude` / `longitude` 数值字段；缺省或同时 `null` 表示未填写手动位置，不改变旧数据；探针近似坐标仅用于管理员地球视图，不写回元信息或自动公开。服务器 JSON 文件与原有备份一起保存。

## 地理数据来源

海岸线使用 Natural Earth `ne_110m_land.geojson`，以两位小数保留坐标，只用于轮廓绘制，不包含政治边界。

- 公有领域说明：https://www.naturalearthdata.com/about/terms-of-use/
