# Cloudflare 自动绑定节点域名（v0.3.8）

服务器卡片的“安装 / 更新”窗口可勾选“通过 Cloudflare 创建 DNS 并设为默认节点域名”。Agent 接入服务器先选择 Xray / sing-box，再进入相同安装窗口。已安装的服务器可使用“绑定 CF 域名”单独绑定，不重装内核。

先在“系统设置 → Cloudflare DNS”保存 API Token（推荐，目标 Zone 的 Zone Read + DNS Edit）或 Global API Key 与账号邮箱。凭据加密保存，可在后续安装中复用，不回显密钥。保存后自动同步域名，也可手动重新同步。安装窗口直接选择已同步域名，自动生成 node- 加 12 位随机十六进制的子域名前缀；支持重新随机或自定义单级前缀，完整域名即时预览。填写服务器公网 IPv4/IPv6 后确认绑定。支持现有 CF 账号中的 DNS 区域，不购买或注册新域名。

## 执行顺序

1. 管理员确认域名、IP 与安装操作。
2. 查询 Cloudflare 中的 Zone 和同名记录。
3. IPv4 创建 A，IPv6 创建 AAAA，TTL 自动，DNS Only（灰云）。相同地址的灰云记录直接复用；CNAME、橙云、不同地址或另一地址族的同名记录会停止处理，不覆盖或删除。
4. DNS 创建成功后，将服务器的 `nodeAddress` 设置为域名。SSH 管理地址不改，Agent 心跳身份不变。
5. 安装模式继续启动原有安装任务；仅绑定模式结束操作。DNS 失败不启动安装。安装失败时保留 DNS 与默认节点地址，不自动回滚远端记录。

新建/导入的节点通过已有统一节点地址逻辑优先使用 `nodeAddress`，因此默认使用该域名。已有订阅中的节点地址不自动改写，需要重新导入或编辑。

域名是客户端连接服务器的地址，不是 Reality 伪装站。不会自动替换 Reality SNI/public key/short ID，也不会自动申请 TLS 证书。TLS/WSS 节点仍需正确配置证书和对应 SNI。普通 Xray 直连代理不能依赖 Cloudflare 橙云转发，所以默认固定灰云。

## 凭据与故障处理

CF 凭据通过 Fernet 加密存储到面板的 remote/servers.json，使用现有 credentials.key；备份时两者需要一起保留。管理员接口只返回是否已配置、邮箱、域名列表和版本，不返回密钥或密文。浏览器不持久化密钥，保存操作完成或失败后清空输入。安装使用服务端保存的凭据并检查版本，不要求再次填写。删除凭据同时清除本地同步列表，但不删除 CF 中已有 DNS。原单次凭据接口保留兼容。Cloudflare API 地址固定，不接受自定义上游，禁止跳转携带凭据，不回显上游可能包含敏感信息的错误正文。

接口只允许管理员并沿用同源/CSRF 检查；普通订阅用户不可调用。域名必须属于填写的 Zone；服务器地址必须为公网单播 IP。AWS 公网 IP 应从实例控制台确认，网卡私网 IP 不适合填写。

上游请求超时可能已经创建记录，此时提示先核对再重试；重试发现完全相同的灰云记录会复用。DNS 成功但本地地址被并发修改或保存失败，会明确报告部分成功，不删除 DNS。解析缓存可能导致新域名不是立即生效，面板不承诺 DNS 传播时间。

## 验证

- Go Web/remote 全量包测试通过。
- CF API 模拟服务覆盖 Token、Global Key、A/AAAA 创建、相同记录复用、不同地址/CNAME/橙云/双栈冲突、权限拒绝和凭据不进入错误信息。
- 匿名、CSRF、私网/回环/多播地址拒绝，域名输入校验；节点域名继承及并发旧值写入拒绝。
- 上述专项 race 测试通过。
- 浏览器验证安装窗口、Global Key 邮箱、取消后清空凭据和手机布局，以及原页面和编辑保存回归。

没有使用用户的真实 CF 凭据创建公网 DNS，也没有为验证而安装远端内核。实际 Cloudflare 权限、账户区域及节点联通性以真实操作结果为准。

## 域名同步与版本保护

同步读取凭据实际可访问的 Zone，按每页 50 项完整分页，最多 5000 项；权限受限 Token 只能看到授权的域名，Global API Key 取决于账号权限。同步失败、重复分页或超出上限不会用不完整列表覆盖旧数据；同步列表是快照，域名变更后点击重新同步。

保存/删除/同步使用版本检查，避免并发页面覆盖新凭据。更换凭据后清空旧域名列表，必须重新同步。安装窗口持有旧版本时明确要求重新打开，不会悄悄使用换过的账号创建记录。

新增验证：加密落盘无明文、读取不回显、版本冲突、删除密钥及列表、分页与重复页拒绝；浏览器验证真实隔离后端保存、模拟 CF 同步、域名下拉、随机与自定义前缀、取消和手机布局。未使用真实 CF 凭据写入公网 DNS。
