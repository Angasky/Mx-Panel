# 批量编辑与内核安装（v0.3.9）

服务器列表勾选后，工具栏提供“批量编辑”“批量安装 / 更新内核”和“批次进度”，原有批量移动分组继续保留。每批最多 20 台。刷新服务器列表保留仍存在的勾选项。

## 批量编辑

只修改显式勾选的字段：服务器名称、默认节点连接地址、内核类型（Xray / sing-box）。名称和节点地址支持 `{n}` 序号及 `{id}` 服务器 ID；保存前逐行预览。节点地址留空恢复默认来源。

这不是 DNS 创建功能。CF 自动 DNS 绑定继续通过单台安装或“绑定 CF 域名”使用，不能仅填写批量地址模板就认为 DNS 已创建。SSH 地址、密码、管理密钥和主机指纹不在批量覆盖范围。

逐台保存并返回各台成功或失败原因，成功项不会因其他项失败而回滚。旧 Agent 未授权、正在执行远端操作、已有待核对状态或限速策略等沿用原有保存限制。切换内核会清理原内核管理状态，应先备份；不会自动卸载远端另一种内核。

## 批量安装 / 更新

针对已授权 SSH、安装模式、内核为 Xray / sing-box 的所选服务器。每台使用自己的当前内核类型；需要统一类型时先批量编辑。整个批次预检不通过不会创建队列。

后台并发启动原有安装任务，默认同时 5 台（选择不足 5 台时界面按所选台数），可设置 1–20 台；完成一台后自动补入下一台。不同机器独立运行，配置校验、重启、输出日志与失败诊断保持原有流程。不要求浏览器保持打开，不因关闭窗口或刷新而取消。可以在“批次进度”查看每台结果、打开安装日志。

默认一台失败后停止后续派发，也可选择继续。点击“停止后续派发”不会强制终止正在运行的远端命令；未启动机器会跳过，批次等待所有运行中的任务结束后停止。

只允许一个批次运行，重复创建被拒绝；单台与批量安装合计最多同时 20 台，全局满额时批次等待空位，不误报安装失败；同一台服务器仍禁止重复安装。如果排队期间服务器记录发生变化，安装前的原子版本核对会阻止按旧确认执行该台任务，并报告配置变化。

只保存最近一个批次。状态和每台安装任务 ID 持久化。面板重启后未完成批次标为中断，不自动重放远端安装；需核对原日志和实际服务状态，再重新勾选需要处理的服务器。不能把安装任务中断简单视为远端完全没有变化。

## 验收

- Go 全量测试通过。
- 队列 race 测试覆盖串行兼容、多台真实同时启动、并发上限与空位回填、全局满额等待、默认并发和范围校验、重复提交拒绝、停止后续、失败即停、失败后继续、排队时配置变化拒绝，以及重启中断不重放。
- 管理接口匿名/同源保护、编辑字段白名单、部分成功结果与未确认安装拒绝通过。
- 浏览器验证批量编辑预览、取消、真实隔离后端保存、保存后勾选保持；批量安装取消不创建任务；批次进度与手机布局，以及 28 页和编辑操作回归。

安装 worker 测试使用隔离执行器，不在用户生产服务器上批量安装或重启代理服务。实际网络、软件仓库和服务器配置结果以每台安装日志为准。
