# 外部订阅流量汇总

v0.1.30：管理员「设置 → 外部订阅流量」。添加名称和 HTTPS 订阅链接，点击「保存并读取」。这是独立的外部额度记录，不导入节点，不修改本地订阅配额，不触发远端服务管理。

读取服务商标准 `Subscription-Userinfo` 响应头中的 upload、download、total 和可选 expire。必须有前三项且数值有效；缺少、重复或非法字段视为未知，不能当零流量。total=0 不自行解释为无限。地址必须为 HTTPS、公网目标；解析时固定验证过的 IP，拒绝私网及跳转降级 HTTP。响应正文不读取、不持久化；使用 GET 兼容不支持 HEAD 的服务商。

每个订阅至少间隔 60 秒手动刷新，最多保存 50 个。v0.1.32 可单独开启后台自动刷新（默认关闭），未开启时仍需手动操作。每个 UTC 日期只保留最后一次成功快照，保留最近 30 个自然日；失败保留尚未过期的历史值并标记错误。曲线显示上传/下载累计值，套餐重置造成的下降不解释为负用量，也不将相邻快照之差宣称为每日账单。

汇总纳入最近 24 小时读取成功且最近一次请求未失败的来源。不同套餐的重置周期可能不同，合计并非统一周期账单；重复添加同一订阅会重复统计。超过 24 小时的值标为过期，失败和未知不纳入汇总。

仅管理员可读写，普通用户和公开探针 API 不暴露这些信息。链接使用既有 credentials.key 加密，API 不回传链接或密文，错误不包含上游 URL 或 Token。数据存于权限 0600 的 external-traffic.json；备份需同时保留 credentials.key。删除同时移除链接和该来源快照。

验证使用模拟 HTTPS 响应头、隔离数据和被拒绝的私网测试地址，未读取真实机场链接。覆盖数值/重复字段校验、失败保留、过期清理、刷新限流、加密、重启、删除、管理员/普通用户隔离；浏览器验证保存、未知提示、链接隐藏、删除和响应式布局。实际服务商不一定提供该标准响应头，应以其后台账单为准。

## v0.1.32：按来源自动刷新

每个来源可选 1、6、12、24 小时间隔，勾选「自动刷新」并点击「保存刷新设置」，确认后生效。旧数据默认关闭。启用或修改设置后，第一次请求安排在所选间隔之后，不立即请求；可自行点击手动刷新。

后台每 30 秒选取一个最早到期来源，单次请求最长 20 秒，与监控采样和通知投递分开运行。成功后按配置间隔安排下一次；失败依次按间隔的 2、4、8…倍退避，上限 24 小时。成功后清除失败次数。页面显示下次计划时间和失败次数；计划不是整点保证，多来源会排队，停机期间不补造每日快照。

下次计划持久化，进程重启不会把全部来源重新立即请求。发请求前先保存下次时间，进程中断可能延迟一次采样；不承诺恰好一次投递。手动刷新成功或失败同样更新计划。停止自动刷新、删除或改设置后，已发出的请求无法撤回，但旧返回结果会丢弃，不能重新启用或覆盖新状态。

API 的 PUT 仅管理员可用，要求来源 ID、auto 开关以及有效 interval；旧客户端的 POST 手动刷新保留已保存的自动刷新偏好。没有新增数据权限或公开字段，订阅地址与内部调度版本不回传。

测试：默认关闭、不提前请求、间隔去重、失败退避上限/恢复、重启持久化、同一秒关闭再开启时丢弃旧结果、关闭后不请求、普通用户拒绝，以及真实浏览器开启/保存/计划时间/关闭。使用受控请求与隔离数据，不启用生产来源自动刷新。
