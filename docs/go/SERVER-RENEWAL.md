# 快速登记服务器续费

v0.1.31：服务器监控 → 服务器详情 → 地域与续费 →「我已续费 · 登记新到期日」。先保存计费周期，按需保存到期日；未保存的表单修改不参与计算。填写服务商 HTTPS 网站后，同处提供「前往服务商」链接。

支持月、季度、半年、年。先选择从原到期日延长，或从今天（UTC）起算；显示原日期、新日期和公开状态。只有勾选「我已完成实际续费，确认以上日期正确」才可提交。一次性项目不支持自动延长；新日期必须晚于原到期日，不能借登记操作缩短期限。没有原到期日可选今天起算。

短月取目标月份最后一天，例如 1 月 31 日加一个月为 2 月末，闰年 2 月 29 日加一年为平年 2 月 28 日。每次从当前选择的起点计算，不猜测服务商的账单锚点；后续续费可能以当前的 28 日起算。若服务商日期不同，请返回手动填写真实日期。

预览只读，POST 使用当前元信息及新日期的版本摘要，和普通元信息保存使用同一锁及原子文件写入。重复点击、并发登记、预览后修改元信息或跨 UTC 日期导致今天起算结果改变时，旧摘要拒绝提交，须重新预览。重试旧请求不会重复延长。

此功能只登记面板到期日期，不执行支付、不调用服务商续费接口、不延长用户订阅、不重置服务器流量周期，也不重启节点。若服务器元信息已设为公开，新日期会随现有监控分享公开。普通用户不能预览或登记。

通知巡检会读取新到期日。尚未发送、已失效的旧服务器/订阅到期提醒在下一轮巡检取消；已发出或正在投递中的消息不能撤回。新日期仍在提醒窗口内时可生成新的提醒。v0.1.31 的入口在管理网页；v0.2.17 已新增可选 Telegram「我已续费」预览/确认按钮和用户授权，见 [通知中心](NOTIFICATIONS.md)。未向真实 Telegram 会话发送测试消息。

验证：月末、闰年、跨年、起算方式、拒绝缩短及一次性项目；并发相同请求只成功一次、预览无副作用、重启持久化、匿名/普通用户/跨站请求拒绝、失效到期队列取消。真实浏览器覆盖勾选确认、日期更新、六主题及三种宽度。
