# 外部订阅按节点选择导入（v0.2.43）

入口：订阅管理 → 订阅转换工具 → 导入外部订阅。填写地址，读取预览后选择节点，再确认导入。

预览仅展示支持节点的名称、协议和序号，不展示地址、密码、UUID 或原始节点对象。默认选中全部有效节点，可取消全部选择、搜索中文名称/协议并选择全部匹配结果；每页 50 个，最多沿用解析器的 20000 节点上限。隐藏/其他页的已选节点仍会导入，选择数量明确显示。同名节点按序号区分。

确认时重新抓取并解析上游；校验摘要绑定目的订阅 ID、来源 URL 和原始响应内容。来源地址、响应内容或节点顺序发生变化会返回 409，要求重新预览，不导入任何节点。即使只改注释也需重新预览；动态生成内容的来源可能需要在内容稳定时操作。版本摘要不保存源凭据，不能用于绕过管理员或来源访问限制。

只将明确选中的节点按上游顺序交给已有导入事务，继续支持重名改名/跳过/替换、指定策略组、主备与专属用户保护、本地标签保留、配置备份和镜像失败回退。不导入上游策略组或链路关系，不建立定时同步。来源读取保留现有 SSRF/DNS/大小/并发限制。

请求：预览 POST /admin/api/import-subscription/preview 新增 nodes（index/name/type）和 revision。确认 POST /admin/api/import-subscription 带 selected 整数序号数组和同一 revision；拒绝空数组、重复、负数、越界及缺失版本。旧 API 不带 selected 与 revision 时继续按原方式导入全部；网页始终走明确选择模式。

验证：后端真实接口使用可控 fetch 函数覆盖只导入选中项、同名节点、版本/URL 变化、空选择和凭据不泄露；旧导入、权限与来源限制回归通过。Chromium 使用受控预览/错误响应验证 65 节点分页、中文搜索、选择请求、异常恢复、特殊字符和六主题四宽度。未请求真实第三方私有订阅或修改生产配置。
