| Linux / fnOS 原生客户端 | 未实现 | 独立客户端、签名打包和平台实测，面板网页与二维码不等于客户端 |

| 重新识别地区 / 修正旗帜 | 本批完成 | 节点管理支持绕过七天缓存重新查询公网 IP 国家；替换前缀并更新配置引用，未修改服务器资产名称 |
| Tailscale 节点导入和客户端下发 | 未实现 | 与私有组网控制平面及客户端格式兼容联动 |
| 主控域名变更后共享服务器自动跟随 | 待独立核查 / 未新增 | 需可验证的主控身份迁移，不能直接相信远端重定向 |
| 多套餐独立限速 / 连接数 / IP 限制 / 单份重置 | 部分实现 | v0.3.28 按授权独占订阅逐份显示到期日、应用模板和单份重置；共用入站按用户限速、连接数 / IP 上限仍未实现 |
| 策略组一键排序 | 本批完成 | 保留勾选和内置策略 / 级联组所在位置；地区按旗帜，服务器按连接地址；保存后生效 |
| 节点行内配置外部中转 | 本批完成 | 快速打开双服务器向导并预选该节点为落地；创建使用已有确认与去重流程 |

## 后续依赖顺序

1. 实际代理出站诊断与现有中转 / 删除回归。
2. 用户套餐模型、独立出口映射、多套餐限额与周期修复预览。
3. XHTTP 高级配置保真、客户端导入与模板兼容。
4. 私有组网控制平面与管理员设备接入，然后子网路由 / 中继 / Tailscale 节点。
5. 原生客户端 / fnOS 分发与 1000 用户场景基准测试。

本批全部新增测试均使用隔离数据；未对生产用户批量改旗帜、改套餐或重置流量。
