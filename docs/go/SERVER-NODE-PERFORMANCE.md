# 节点读取与操作优化（v0.3.12）

## 参考与实现

参考 https://github.com/Teminuosi/3x-ui （检查提交 b70a4bb）的列表读取与运行时变更分离设计：其 GetInbounds / GetInboundsSlim 从数据库读取，AddInbound 尝试运行时添加后再决定是否重启。本项目为多服务器 SSH 管理，因此按现有事务、校验和回滚流程独立实现连接复用及显示快照，没有直接替换为该项目的运行时接口。

独立 Xray / sing-box 操作在同一台机器上短期复用已校验主机指纹和认证信息的 SSH 连接，闲置 30 秒关闭、最多保留 32 条。连接被独占借用；主机、端口、用户、认证或指纹变化时不复用。取消或远端命令失败的连接丢弃，不重放写请求。创建节点和中转的后续用户配置、计量检查等步骤可复用连接，配置校验、版本核对、回滚和用户归属检查保留。

## 列表与忙碌处理

交互列表合并同一服务器的并发读取，使用最长 5 秒的显示快照；注册资料变化或操作结束后失效。服务器正忙时可显示相同注册资料下最近 60 秒的快照并明确标记。无快照时等待当前操作释放锁，超时后页面显示重试，不再整页报“页面加载失败”。手动刷新绕过正常短缓存，正忙时仍可展示带提示的快照。

快照仅用于显示，不能用于计费、删除或配置修改。列表 GET 不再同步等待订阅清理，也不清理 Web 面板中转资源；后台的权威读取与核对流程继续执行。真实写操作仍独占服务器；并发写不会绕过保护。原始内核配置的只读请求也可等待锁。

## 订阅选择

绑定窗口显示所有订阅，包括已绑定、部分绑定和未绑定项。已全部绑定项禁用选择并显示状态，不再隐藏；增加总数和刷新按钮。新建订阅从当前索引读取，选择器不依赖页面上旧的订阅缓存。

## SNI

移除 CF / AWS 自有候选域名（含 Amazon、CloudFront、Twitch 等已有候选），并过滤旧固定库中的同类条目。扫描和新建 Reality 模板也拒绝这些已排除的域名。此处按域名归属过滤，并非声称其他站点从不使用 CF / AWS 网络。

固定库只收录参考服务器通过 TLS 1.3 证书校验及实际 Reality 握手的结果。快速扫描只测试固定 IP 的 TCP 443 延迟；不保证当前服务器或未来仍能通过 TLS/Reality。普通候选列表不代表全部站点已通过验证。

## 验证

两台现有 Xray 服务器只读实测：改动前连续真实读取约 2.64 / 2.63 秒和 2.55 / 2.54 秒；复用后首次约 2.65 / 2.59 秒，强制真实刷新约 0.99 / 0.59 秒。短期显示快照约 0.55 / 4.19 毫秒（后端方法耗时，不含 HTTP、浏览器渲染）。不据此承诺所有网络同速，也没有在生产服务器上试建或重启代理来测创建速度。

验收覆盖连接复用及认证变化拒绝、读等待/写互斥、并发读取合并、缓存隔离及资料变化、SNI 排除、新订阅索引刷新、忙碌页面重试、订阅状态展示及 28 页浏览器回归。
