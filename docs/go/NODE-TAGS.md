# 节点多标签（v0.2.27）

管理员在「节点管理 → 我的节点」点击节点卡片的「标签」，可以为一个节点添加多个地区、用途或线路标记。勾选节点后，在「批量操作 → 批量管理标签」一次处理最多 500 个节点。支持添加（保留已有）、移除指定、替换全部、清空四种模式，均先预览各节点修改前后的标签，再确认保存。

## 筛选与搜索

- 节点卡片展示多个标签，标签筛选下拉框显示数量，并提供「未打标签」。
- 中文或英文关键词搜索同时匹配名称、协议、服务器和标签；标签筛选与搜索、协议筛选叠加。
- 标签区分大小写，筛选采用完整标签匹配。每行输入一个标签，每节点最多 16 个，每个最多 32 个 Unicode 字符；不允许重复、控制字符或首尾空白。表单会去除首尾空白并忽略空行。
- 「选择当前结果」只选择当前筛选结果。切换筛选不会取消之前的选择，批量弹窗会明确提示包含筛选隐藏的已选节点；需要时先取消选择。

## 保存与生命周期

标签存于订阅 YAML 的节点扩展字段 `x-mxioc-tags`，随配置备份和加密备份一起保存。客户端 YAML、所有转换源和公开下载都会移除此字段；标签不改变路由、策略组、节点名称或连接参数，不代表节点真实地理位置、解锁能力或健康状态。

节点编辑器正常编辑/重命名时保留标签，删除节点会一起删除标签。外部订阅导入覆盖同名节点时保留本地标签，忽略上游管理标签；新导入节点默认无标签。直接编辑原始 YAML、整份恢复/替换配置则以新配置中的标签为准，不自动合并。标签是当前订阅的管理信息，不自动同步给其他订阅或远端节点。

确认绑定订阅内容、元信息、节点选择、操作类型及标签值，期间发生修改会要求重新预览。整批保存沿用配置备份、镜像写入和失败回退；无效节点、标签超限等情况不会部分保存。主备链路中的节点允许修改标签，其连接参数和引用关系仍受原有保护。

## API 与验收

管理员 `POST /admin/api/nodes/tags`，`X-Profile` 指定订阅。

预览请求：`{"action":"preview","names":["节点 A"],"mode":"add","tags":["香港","流媒体"]}`。响应包含 changes（name/before/after）、unchanged 数量及 revision，不返回节点地址或凭据。确认传相同计划、`action:apply`、revision 和 `confirmed:true`。clear 模式 tags 为空，其他模式至少一个标签。

Go 全量测试与专项竞态测试覆盖预览、并发、无效输入、过期提交、权限、主备保护、导入保留、备份及导出剔除。真实 Chromium 验证添加/替换/清空、中文搜索、标签筛选、特殊字符转义、各可用客户端下载，以及六主题四宽度。未改变生产订阅进行验收；不宣称与妙妙屋内部标签格式兼容。
