# 批量重置订阅链接（v0.2.28）

入口：管理员「订阅管理 → 我的订阅 → 批量重置订阅链接」。弹窗从后台重新读取全部订阅，可勾选部分或选择全部；选择不受订阅列表搜索/分页影响。一次支持 1–1000 份订阅，包括主订阅、过期或暂停访问的订阅。

## 使用步骤

1. 选择要处理的订阅，点击「预览链接重置」。此时不生成新地址、不写入、不创建备份。
2. 核对订阅名称、数量和自定义地址数量。
3. 勾选旧链接失效确认，再点击「确认重置所选链接」。后端先备份订阅索引，再一次性保存所有新地址。
4. 从订阅列表重新复制链接，重新分发给用户。已授权普通用户可在订阅中心获得新地址；客户端需要替换原订阅 URL。

预览后订阅列表或设置改变，或者提交时变更选择，操作会被拒绝，须重新预览。并发重复提交仅一次成功。关闭窗口不会取消已经发往服务器的确认请求；响应中断时，应先刷新列表核对地址，避免无谓的二次轮换。

## 生效范围

每份选中订阅生成独立的 50 位十六进制随机标识（200 位随机熵），避免与任何当前地址重复。自定义地址也切换为随机地址。旧原始 YAML 下载地址及所有客户端转换地址失效，新二维码/转换地址通过已有订阅页面重新生成。未选订阅不受影响。

只轮换下载能力令牌：不改变用户授权、账号密码、节点 UUID/密码、额度/用量/到期日期、IP 白名单、暂停状态或远端服务。过期、耗尽或已撤销访问的订阅不会因此恢复访问。已经下载的节点配置和凭据仍可能继续使用，若节点凭据泄露，还需处理对应节点/用户；此功能不宣称完成远端凭据全量重置。

## 备份与存储

确认前将原订阅索引写入数据目录的 `subscription-rotation-backups/profiles-时间-随机值.json`，目录创建权限 0700、文件 0600，写入和同步失败则不修改地址。所有新标识生成后通过一次原子索引替换提交，不循环逐份保存。响应只返回订阅 ID、名称、原自定义标记、版本摘要及备份文件名，不返回新旧令牌。

这是包含订阅访问令牌和元信息的私有服务端备份，不是下载给用户的订阅 YAML 备份；暂不提供网页恢复/自动清理。恢复旧索引可能重新启用泄露的旧链接，并回退其他索引设置，请仅在服务器故障恢复时核对使用。

接口：管理员 `POST /admin/api/profiles/rotate-links`，预览 `{"action":"preview","ids":["订阅ID"]}`；确认同一 ids、`action:apply`、预览 revision 和 `confirmed:true`。无需 X-Profile，范围以 ids 为准；普通用户不可调用。

## 验收

全量 Go 和专项 race 覆盖权限、来源、确认、选择/版本变更、备份失败、并发、重启持久化以及节点/未选订阅不变。真实 Chromium 验证全部/部分选择、预览/确认、旧链接失效、新链接下载、普通用户订阅中心刷新，以及六主题 × 四种宽度。测试使用隔离数据，不轮换生产订阅。
