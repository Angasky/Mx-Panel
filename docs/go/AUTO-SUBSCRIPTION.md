# 自动识别客户端订阅（v0.2.44）

订阅总览、客户端链接和用户授权订阅窗口提供“自动识别客户端（实验性）”，可复制或扫码导入。地址为 `/convert/{订阅标识}/auto`，无需修改现有专用链接。

根据唯一 User-Agent 产品标识选择格式：Clash/Mihomo 使用完整原始 YAML；Shadowrocket、v2rayN/NG、sing-box、Surge、Loon、Quantumult X、Stash、Surfboard、Egern 使用现有基础转换器。非 Clash 格式不保证完整分流、DNS、TUN、远程规则和主备配置。sing-box 仍受实验性导出开关控制。

未知、缺失、重复、过长或互相冲突的客户端标识返回 400；无兼容节点或禁用的导出返回 404。旧 Quantumult 不自动识别为 Quantumult X。浏览器不下载自动链接，请用专用格式下载。

访问额度、有效期、撤销、IP 白名单与浏览器限制沿用原订阅检查。User-Agent 可伪造，仅用于格式选择，不是权限凭据。响应禁止缓存，HEAD 不返回配置正文。服务器筛选仍只支持已有节点 URI 格式；此卡片在服务器筛选时隐藏。

验证：本地 HTTP 识别和专用链接内容等价、访问限制、禁用导出、重复标识、HEAD；真实 Chromium 卡片、二维码、跳转及六主题四宽度。未完成所有手机客户端实机导入和连接验证。
