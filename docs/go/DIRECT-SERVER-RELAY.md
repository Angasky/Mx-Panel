# 托管服务器内部中转（v0.3.11）

进入“链式代理” → “服务器内部转发” → “选择托管服务器创建中转”。入口选择方式使用“直接选择托管服务器”，选择已授权且已安装或接管内核的服务器，再选择当前订阅中的一个普通落地节点。

此方式不要求服务器预先存在入口节点，落地服务器也不要求托管。落地必须是当前订阅中可导出且目标内核支持的普通节点；不接受链式代理或已生成的服务器链路作为出口。入口与已知相同服务器地址的出口会拒绝。

支持已有 Xray、sing-box 以及已接入的 x-ui / 3x-ui / x-panel。Xray / Web 面板入口使用 Reality；sing-box 可选 Reality 或 VMess TCP。Reality 需在所选入口服务器测试 SNI，切换服务器清除先前测试结果。仅监控 Agent、尚未接管配置、正在安装的服务器不出现在可用选择中。需要先启用管理权限并准备内核，此功能不隐式安装软件。

确认后复用远端中转创建流程，在入口服务器创建入站、落地出站和专属路由，必要时重启内核。路由确认后才创建订阅独立用户并加入所选策略组，沿用流量和有效期限制。客户端只连接生成的入口节点，可使用兼容的单节点链接；不是客户端 dialer-proxy 链。

沿用操作标识和资源归属检查；重复请求不会重复创建用户或中转。失败时在原窗口继续核对，不要重新发起另一条同名中转。列表显示入口服务器名称及落地节点，删除使用现有服务器链路清理流程。原“从已有入口节点匹配服务器”方式和 Mihomo 客户端链式代理保持兼容。

验收包括 Xray / sing-box 单出口直接创建、无入口节点、重复请求、无权限/不存在服务器/同机出口拒绝、旧链路回归，以及浏览器选择、确认取消、提交参数和移动布局。远端操作使用隔离测试执行器，未在生产服务器试建代理。
