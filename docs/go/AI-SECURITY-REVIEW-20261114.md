# AI / Agent 安全与功能验收

日期：2026-11-14。审查基线：v0.2.4（4c220c5）。修复版本：v0.2.5。

结论：发现了需要修复的安全与功能缺陷，不能把旧版称为“没有漏洞”。本次修复及回归通过后，可用于管理员审阅确认的运维辅助；仍不适合不经审阅的全自动 root 运维。自动化检查只能说明所覆盖用例与已知漏洞库的结果，不能证明绝对安全。

## 修复结果

| 问题 | 风险与证据 | 修复 |
| --- | --- | --- |
| 慢请求占住 AI 全局锁 | 中：设置与执行接口在锁内读取请求正文；隔离测试复现其他 AI 请求被阻塞 | 锁外读取，正文上限 64 KB；保持后续内容类型和 JSON 校验 |
| 本机脚本继承进程环境 | 中：测试复现脚本读到合成环境密钥，BASH_ENV 在命令前执行 | 固定 /bin/bash、工作目录和最小环境，不继承面板环境或启动脚本；这不构成 root 文件系统沙箱 |
| 改 AI 设置后旧计划仍可执行 | 中：复现更换模型/Key 后旧计划仍返回成功 | 保存接入设置时撤销所有待执行计划；取消操作不再受模型关闭或目标删除阻碍 |
| 目标核验与获取 SSH 凭据分离 | 高影响风险：代码审查发现两次读注册表之间的竞态窗口；定向测试验证旧身份拒绝与连接快照不可变 | 对同一份注册记录核验并解密连接；创建节点/中转在注册表更新共用的服务器锁内再次验证身份；本机计划绑定机器、启动实例及数据目录，旧本机计划失效 |
| 审阅内容可含控制/不可见字符 | 中：复现含回车、终端控制与双向排版字符的脚本被接受 | 写操作计划拒绝控制及 Unicode 格式字符，保留正常换行和制表符 |
| 配置摘要透传未经检查的字段 | 中：异常协议/传输/规则字段可携带任意文本 | 类型、传输、策略组、规则类型和 IP 模式改为枚举白名单，TLS/UDP 等仅接受布尔值 |
| JSON 转义绕过 Key 回显替换 | 低：模型可在 Agent JSON 中使用转义字符，经第二次解码还原 Key | 解码后再次检查；回答脱敏，写操作包含当前 Key 时拒绝生成计划 |
| 截断计划、计费显示和中断状态不准确 | 功能：只展示最后一次模型 token，重启后的旧 running 状态与新聊天共用标记 | 拒绝被截断计划；累计本轮模型 token；单独跟踪执行 ID，中断结果显示未知且不自动重放 |
| 容器内本机执行缺少 bash | 功能：Dockerfile 审查确认旧镜像未安装 Agent 所需解释器 | 镜像补齐 bash、iproute2、procps；诊断标注容器及不支持 systemd 的环境；未在本次实际构建/运行容器 |
| API URL 和页面竞态边界 | 功能/加固：非法端口或空查询标记到请求时才失败；旧设置/确认回调缺少完整页面世代校验 | 提前校验端口与查询；设置响应、操作按钮核验当前账号世代及会话视图 |

## 依赖检查

使用 govulncheck v1.9.0 和 Go 官方漏洞数据库（扫描时数据库更新时间为 2026-11-11）。基线扫描命中四个不同告警，不应把不同调用栈计作多次独立漏洞：

- GO-2026-6859：Go HTTP/1 服务 MaxBytesReader header race，可导致崩溃；扫描确认存在项目函数调用路径。
- GO-2026-6860、GO-2026-6866：x/net HTML 相关问题；扫描只命中模块版本，未报告本项目调用受影响函数。
- GO-2026-5932：x/crypto 中已弃用 OpenPGP 包的安全告警；未报告本项目调用该包。

已将最低 Go 版本升级为 1.26.11，x/crypto 升级为 0.59.0，x/net 升级为 0.62.0，并同步间接依赖。升级后的源码复扫无 finding。发布包必须使用修复后的工具链构建，不能仅更新网页。

## 验证范围与结果

- 全仓库 `go test ./...` 通过；AI、Web、SSH、订阅控制器竞态检查通过，新增安全用例在新工具链下复验通过。
- 身份验证：匿名访问拒绝；普通用户无法执行 Agent；跨域写请求拒绝；每账号 Key/对话隔离，目录与文件权限及加密保存保持有效。
- 确认执行：确认前不执行；并发八次确认仅执行一次；过期、取消、旧目标身份、已运行与中断计划不可重放；设置更换会撤销旧计划。
- 执行环境：使用临时文件验证真实命令执行，本机超时取消进程组，输出有上限，原始输出不自动发给模型；节点/中转通过隔离后端验证现有控制器调用契约，不在生产创建资源。
- 网络与模型：四类协议模拟响应验证，内网/回环/映射 IPv6/保留地址拒绝，禁止环境代理和 HTTP 重定向；实际 307 响应未触发第二次带认证请求。错误不回显上游原始响应与 Key。
- 解析器：10 秒模糊测试完成约 374,935 次输入执行，未出现崩溃；这不是长时间持续 fuzz 或完整形式验证。
- 浏览器：确认勾选、失效确认回调、账号切换迟到响应、恶意 HTML/脚本转义、停止、草稿、拖动、最大化、六套主题及三种宽度通过。
- 未使用真实付费 Key 验证供应商在线返回质量；模拟协议通过不保证所有第三方兼容网关行为相同。

## 仍未完善的能力

1. **脚本不是沙箱**：管理员确认的命令具有面板服务或 SSH 账号真实权限，可能为 root。提示词无法阻止已经被管理员批准的危险命令；不能承诺模型生成的脚本总是安全。
2. **无通用自动回滚**：卡片中的回滚建议来自模型，不代表已有可用备份。中断/失败可能有部分变更；SSH 断开不能保证远端所有子进程都停止。
3. **无自动修复验收**：退出码 0 或创建接口返回成功不等于故障修复，仍需重新诊断或人工检查。没有通用源码补丁沙箱、差异审核、测试后合并流程。
4. **有界单轮 Agent**：每轮最多 3 次模型决策，执行等待 50 秒；尚非持续后台任务系统，缺少持久任务恢复、长时间流式执行和依赖任务编排。旧执行不会自动重放。
5. **创建功能有前置条件**：容器部署中的「本机」是容器而非宿主机，权限仍为容器服务账号。机器需接入合适内核/面板；脚本需有效 SSH；Reality 需完成 SNI 测试，TLS 需有效证书；不自动为任意机器安装全部依赖。
6. **密钥托管边界**：服务器 root 控制加密数据及本地密钥。账号隔离不等于对服务器管理员的端到端加密；配置域名和主动提交内容可能包含业务信息。

建议使用方式：保持默认问答模式；需要运维时明确选择目标，在已备份且可通过外部 SSH 恢复的条件下，逐项核对并确认。日常已知故障优先使用面板原生操作；复杂脚本保持人工审阅。
