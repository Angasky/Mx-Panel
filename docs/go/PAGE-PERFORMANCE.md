# v0.3.1 页面加载优化

原版 HTML 约 659 KB，没有响应浏览器的 gzip 协商，且 no-store 导致刷新重新下载；工作区资源缺少 ETag，登录页还下载了约 84 KB 的地球组件。

公开 UI 文件现支持 gzip、按表示区分的 ETag、Vary: Accept-Encoding、GET/HEAD 和条件请求。HTML 文件大小、mtime 或文件身份变化时重新生成缓存；固定嵌入资源按名称缓存压缩结果。仅缓存公开界面文件，不缓存登录状态或认证 API；公开 HTML 不包含用户数据。3D 地球改为打开时加载，失败可重试。

## 对比

2026-11-15，隔离本机服务与 Chromium，下载带宽 200000 字节/秒（约 1.6 Mbps）、150 ms 延迟、4 倍 CPU 降速，默认主题。计时终点为登录表单可见；冷访问后等待字体及网络稳定，再测试热访问。以下是一次配对复测，不代表真实用户网络 SLA。

| 指标 | v0.3.0 | v0.3.1 |
| --- | ---: | ---: |
| 登录页冷访问可用 | 7185 ms | 3034 ms |
| 登录页热访问可用 | 4330 ms | 581 ms |
| HTML 响应体 | 658801 B | 约 186682 B |
| 热访问 HTML 网络传输 | 659101 B | 300 B（304 响应头） |

冷访问可用并不表示中文字体已全部下载完成；字体使用 swap，首次可先显示系统字体。测试没有测量 Cloudflare 挑战、国际链路、用户设备或真实账号大量数据下的接口延迟。

Go 全量测试通过；补充 gzip 解码、q=0 协商、HEAD、304、资源类型及 HTML 更新失效测试。浏览器回归覆盖 28 页、5 种宽度、11 类编辑器、保存与取消、普通用户、公开监控，并验证地球首次不加载、主动打开后可用。
