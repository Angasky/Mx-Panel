# 用户套餐、独立出口与周期核对

从 v0.3.28 起，在“用户与权限 → 套餐 / 出口”查看该用户各份授权订阅。当前每份独占订阅作为一个独立套餐管理单元，沿用现有订阅的流量计划、到期日及计量。共享订阅只读，不自动拆分或复制代理凭据。

## 用户专属出口

为一份独占套餐选择当前订阅中的普通出口节点（例如住宅 SOCKS5）。系统把出口快照加密保存，为套餐在各台独立 Xray 上的代理用户 email 生成限定用户的路由和专属 outbound。其他用户不使用该规则，不生成子节点，不改变原订阅 URL、UUID 或分享链接。

入口服务器须为独立 Xray，用户须为 scope=user 的独立身份；sing-box、Web 面板、整入站专属绑定目前拒绝。新加入的代理用户必须先应用出口路由，再授予凭据。源节点后续修改不会静默改动已应用出口，需重新设置以使用新的快照。

批量设置支持：每行“用户名 出口节点名”、完全相同名称自动配对、按套餐勾选预览。一位用户有多份独占套餐时逐份应用。每批最多 30 份；失败逐条显示，共享订阅拒绝修改。

操作会重启涉及的 Xray 内核，不是跨服务器原子事务。每台服务器保存加密恢复日志和出站 / 路由身份摘要；丢失响应后重新核对并确认应用，不直接声明成功。部分失败保留 pending，可继续原操作或清除出口。清除只撤回归属明确的片段；外部配置变化会拒绝覆盖。未完成的服务器操作会阻止其他内核写入，避免恢复覆盖并发修改。

为防止遗失归属，清除出口前不能共享此订阅给另一用户、删除所属用户 / 订阅或解除承载服务器。禁用用户仍遵循原账户登录语义，不自动等同撤销所有代理凭据；订阅到期和额度限制继续由计量后台执行。用户被撤销后的规则可在清除出口时统一移除。

## 独立套餐操作

每份套餐分别显示模板、已用 / 总额度、到期日及出口状态。应用套餐模板沿用已有安全校验：共用用户入站不提供按用户限速，专属入站可使用已有带宽限制。连接数与同时在线 IP 上限尚未实现。不能把本版称为完整多套餐实体与限制能力等价。

“仅重置这份流量”先结算该订阅已采集的用量，再清零该份可见计数，保留远端绝对计量基线、到期日与其他套餐。结算有错误则不重置。

## 周期修复

先展示开始日、重置日前后、保持不变的到期日以及原因。只对开始日可信、仍处于首个有效周期、重置时间缺失或不晚于开始日的记录提供自动修复。已到重置日不能直接延后；开始日不明不能推断；到期日永不自动修改。修复请求带状态摘要，管理员确认后如套餐已变化则拒绝。

## 验证范围

隔离真实 Xray：同一 VLESS 入站两个认证用户分别到不同 HTTP 出口。配置生成、相互隔离、其他用户规则保留、相同请求幂等、持久写入后响应丢失恢复、外部变化拒绝、自环拒绝、新服务器路由继承测试。HTTP 鉴权 / CSRF / 共享订阅拒绝 / 归属删除保护与输出脱敏；单套餐重置不修改另一套餐；周期预览不篡改用量和到期日；浏览器入口与移动端布局。未自动给生产用户设置出口或重置流量。
