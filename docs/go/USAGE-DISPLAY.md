# 流量信息节点（v0.2.47）

入口：订阅管理 → 流量信息节点，也可从设置快捷入口进入。直接在主页面展示，设置按当前订阅独立保存。

## 功能

可独立关闭 v2rayN、v2rayNG、V2Ray 通用、Shadowrocket 基础 URI 订阅里的三个信息占位节点，或者自定义其名称。自动识别链接选中上述格式时同样生效；按服务器筛选仍显示整个订阅的用量，不是该服务器的独立账单。

| 名称模板 | 必需变量 | 默认显示 |
| --- | --- | --- |
| 已用 / 总量 | `{used}`、`{total}` 各一次 | 订阅信息 · 已用 … / 总量 … |
| 剩余额度 | `{remaining}` 一次 | 订阅信息 · 剩余流量 … |
| 到期信息 | `{expiry}` 一次 | 订阅信息 · 剩余天数与 UTC 到期时间，或长期有效 |

模板留空沿用该项默认名称。每项最多 128 个 Unicode 字符，不允许控制/隐藏格式字符、换行或其他变量。显示值来自实际流量记录，沿用原来的数值、二进制换算和 GB 文案。没有设置流量信息时不生成占位节点。

信息节点仍使用不可连接的回环地址与占位凭据，不是代理服务器，不应手动选择。名称与实际导出节点或其他信息节点相同时，信息名称追加“· 信息 N”，不改真实节点名。更改后需要客户端更新订阅；客户端可能仍保留手工加入的旧节点。

关闭显示不会关闭计费、额度、到期、撤销或 IP/浏览器限制，不清空已用流量、不改服务器。标准 Subscription-Userinfo 响应头仍返回。Clash/Mihomo 原始 YAML、完整 JSON、其他客户端配置及主备专用导出不添加这三类节点，因此不受本选项影响；这些格式的已有流量说明保持原样。

## 预览与保存

预览固定使用“已用 20 GB / 总额 100 GB / 剩余 80 GB / 七天后到期”的示例，不读写真实额度、不联网、不发送。关闭显示时预览提示“不生成提示节点”。修改字段使旧预览失效；预览失败清空旧结果。

恢复默认只修改编辑框，需保存后生效。保存期间锁定表单；切换页面或订阅后迟到结果不会更新新页面。同一设置被其他管理员修改时返回冲突，须刷新核对，避免覆盖新设置。

## API 与持久化

仅管理员可访问 `/admin/api/subscription-usage-display`，X-Profile 指定目标订阅。GET 返回 options、revision 及固定示例 names；POST 校验并预览、不保存；PUT 提交 options 与读取到的 revision 后保存。options 包含 enabled（必填布尔值）、used、remaining、expiry（空字符串为默认）。示例响应中的 revision 不能替代之前从 GET/成功 PUT 获取的保存版本。

保存在订阅索引的 usageDisplay 字段，不写入原始 YAML。旧订阅没有该字段时默认启用并使用原名称；YAML 单独备份不包含此设置，完整数据备份需保留订阅索引。

验证：四种 URI 的真实导出解析、隐藏与响应头、原 YAML/流量记录不变、到期拦截、重名保护、无限额度/无期限/未配置状态、非法变量和 Unicode 边界、权限与同源、只读预览、过期版本拒绝及重启回读。Go 全量、专项竞态、Chromium 六主题四宽度与页面交互通过。未修改生产额度，也未进行四种手机客户端实机导入。
